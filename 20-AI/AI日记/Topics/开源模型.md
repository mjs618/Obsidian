# 开源模型

## 简介
- [[20-AI/AI日记/2026/06/2026-06-03|2026-06-03]] NVIDIA 推出开放的 Alpamayo 2 Super，并把 AlpaGym、OmniDreams 与 physical AI agent skills 组合发布，说明开源路线正继续向自动驾驶与 physical AI 整栈开发体系下沉。
- [[20-AI/AI日记/2026/06/2026-06-02|2026-06-02]] NVIDIA 发布开放的 Cosmos 3 并组建 Cosmos Coalition，说明开源模型竞争正在从语言权重开放继续扩展到 world model、合成数据和机器人开发栈。
- [[20-AI/AI日记/2026/06/2026-06-01|2026-06-01]] Mistral 把 Search Toolkit 和 Vibe 一起推进，说明开源路线的竞争点继续从权重开放外溢到搜索/RAG 基础设施、agent 工作流与企业可部署性。
- [[20-AI/AI日记/2026/05/2026-05-31|2026-05-31]] IBM/Red Hat 的 Project Lightwell 加上 Mistral 的 Search Toolkit 说明，开源路线的竞争点继续从权重开放本身扩展到搜索基础设施和安全供应链工程化。
- [[20-AI/AI日记/2026/05/2026-05-30|2026-05-30]] IBM/Red Hat 的 Project Lightwell 把开源安全推成 AI 时代的企业基础设施问题，说明开源竞争正在从“开放模型或代码”扩展到供应链漏洞发现、修复验证和责任协同。
聚焦开放权重、开源许可、推理栈适配、私有化部署和开发者生态变化。

## 待跟踪

- 开源搜索/RAG 基础设施会不会像模型本身一样，成为企业采购里独立的战略层而非附属工具层。
- Project Lightwell 这类企业化开源安全 clearinghouse，是否会真正回流上游社区，还是主要沉淀为商业订阅层。
- Open Agent Leaderboard 是否会沉淀成社区默认基准，并吸引更多 open-weight agent 系统提交结果。
- 开源模型竞争是否会从参数规模转向推理成本、上下文长度、工具链适配和企业私有化部署体验。
- Mistral、Moonshot/Kimi、Qwen、DeepSeek 等开放权重路线，是否会在企业部署和开发者生态中形成不同区域优势。
- 开源许可、训练数据披露和安全评测要求是否会成为开放模型商业化的新约束。

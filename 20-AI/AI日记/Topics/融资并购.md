- [[20-AI/AI日记/2026/06/2026-06-04|2026-06-04]] Factorial 和 DriveNets 的新融资一起说明，资本正在更明确地押注两类 AI 资产：AI-first 工作流操作层，以及承接大规模推理与 agent 流量的网络基础设施。

## 待跟踪

- 头部模型公司的下一轮融资，是否会越来越公开地绑定长期电力、云合同、芯片预付款或联合投资结构。
- agent 时代的并购是否会更多聚焦连接层、评测层与权限控制层，而不只是模型与应用层。
- AI 基础设施公司的 IPO 之后能否维持高估值，关键会不会快速转向真实推理需求与客户结构验证。
- 语音 agent、客服 agent 和垂直流程 agent 是否会成为下一阶段最容易融资的应用层方向。
- 大额融资是否继续偏向“模型 + 交付”与“算力 + 资本结构”两类资产。
- OpenAI 这类带实施团队的新业务载体，会不会改变传统咨询和 SI 市场的估值逻辑。

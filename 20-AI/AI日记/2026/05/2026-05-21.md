# AI日记 - 2026-05-21

## 今日重点

### 1. [[Google-DeepMind]] 的 I/O 总结把 agent 从单点产品升级为横跨搜索、购物、助手和开发工具的默认层
- 类别：平台 / 搜索 / 消费入口
- 时间：2026-05-20
- 摘要：Google 发布 I/O 2026 的 100 项公告汇总，集中呈现 Gemini 3.5 Flash、Gemini Omni、Search agents、Personal Intelligence、Universal Cart、Gemini Spark、Daily Brief 和 Antigravity 等能力。
- 影响：5 月 20 日的汇总比单篇发布更能说明 Google 的真实策略：agent 不再只是开发者 API 或聊天助手，而是被分发到搜索框、购物车、Gmail、YouTube、手机和开发环境里。Google 正试图把“持续观察、持续生成、持续执行”变成跨产品默认能力。
- 相关：[[Google-DeepMind]] / [[算力基础设施]]

### 2. [[算力基础设施]] 的瓶颈继续从 GPU 扩展到 CPU、内存带宽与 agent sandbox 编排
- 类别：AI 基础设施 / 芯片 / agent 运行时
- 时间：2026-05-18
- 摘要：NVIDIA 宣布首批 Vera CPU 系统已交付 Anthropic、OpenAI、SpaceXAI 和 OCI，并将 Vera 定位为面向 agentic AI 的自研 CPU，负责 tool calling、orchestration、RL workload、agent sandbox、long-context state management 等工作负载。
- 影响：agent 运行栈不是“更多 GPU”就能解决。大量工具调用、代码执行、检索、状态管理和沙箱调度会把压力推到 CPU 与系统互联层。算力竞争正在从训练/推理芯片扩展成“GPU + CPU + DPU + 网络 + 沙箱”的整体效率竞赛。
- 相关：[[算力基础设施]] / [[OpenAI]] / [[Anthropic]]

### 3. [[政策监管]] 与 [[Anthropic]] 的交叉继续外溢到宗教、伦理和公共叙事层
- 类别：治理 / 社会接受性 / 公共议题
- 时间：2026-05-18
- 摘要：AP 报道称，Pope Leo XIV 将与 Anthropic 联合创始人 Christopher Olah 于 2026-05-25 发布其首份关于 AI 时代人类尊严的通谕。
- 影响：AI 治理的战场正在从政府、标准组织和企业政策扩展到更广泛的社会价值框架。Anthropic 近期先发布前沿 AI 对话计划，再进入 Vatican 语境，说明模型公司正在把“谁有资格定义 AI 风险与人类价值”变成长期竞争的一部分。
- 相关：[[Anthropic]] / [[政策监管]]

### 4. Google 的 Search agents 和 Universal Cart 说明高频入口竞争开始进入“后台监控 + 主动交易”阶段
- 类别：搜索 / 商业化 / agent 入口
- 时间：2026-05-20
- 摘要：Google 在 I/O 汇总中强调，Search agents 可在后台持续监控网页、新闻、社交、金融、购物和体育等信息；Universal Cart 则把 Search、Gemini、YouTube 和 Gmail 中的购物行为合并到一个智能购物车。
- 影响：搜索入口的下一步不是更长答案，而是持续监控、筛选、提醒和交易执行。商业化也会从广告位进一步靠近“替用户发现、判断并推动购买”的流程，这会改变搜索、电商和个人数据授权之间的边界。
- 相关：[[Google-DeepMind]] / [[政策监管]]

## 趋势点评

过去 24 小时更像是对 I/O 后信号的再归纳，而不是全新发布潮。最值得记录的是，[[Google-DeepMind]] 的 agent 战略已经不是“模型能力 + 一个助手”，而是要把搜索、购物、个人数据、视频生成、开发工具和移动端入口全部接到同一套 Gemini/Antigravity 叙事里。Google 想争的是用户每天最自然发起任务的位置。

第二条趋势是 [[算力基础设施]] 的定义继续变宽。NVIDIA Vera 的叙事说明，agent 大规模运行后，CPU、内存带宽、状态管理、沙箱和工具编排会成为显性瓶颈。后续比较 AI 基础设施公司时，不能只看 GPU 容量，还要看能否支撑大量并发 agent 的系统级吞吐。

第三条趋势是 [[政策监管]] 的公共叙事继续升温。AI 安全与治理不再只发生在 NIST、欧盟或企业 policy 文档里，也会进入宗教、伦理和公共价值讨论。对模型公司来说，社会可接受性正在变成与连接器、算力和模型能力并列的长期资产。

## 后续值得跟踪

- Google 的 Search agents 和 Gemini Spark 是否会形成统一的权限、日志和用户授权模型。
- Universal Cart 会不会把 AI 搜索商业化从广告导流推进到更直接的交易与支付分成。
- NVIDIA Vera 是否会被更多云厂商和模型公司纳入 agent workload 的标准配置，而不是单次展示性合作。
- Anthropic 与 Vatican 相关议题是否会进一步影响其在公共部门、教育和公益场景中的治理形象。
- agent 运行成本的讨论是否会从 token 价格转向沙箱、CPU、检索和长上下文状态管理的整体成本。

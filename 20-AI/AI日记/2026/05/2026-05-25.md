# AI日记 - 2026-05-25

## 今日重点

### 1. [[OpenAI]] 把 Codex 从“能写代码”继续推向“可治理的企业交付层”
- 类别：产品 / 企业交付 / 编程 agent
- 时间：2026-05-22
- 摘要：OpenAI 在 2026-05-22 同日发布 Gartner 企业级 AI Coding Agents 领导者公告，以及 Virgin Atlantic 的 Codex 客户案例，前者强调治理、沙箱、RBAC 和可审计工作区，后者给出 78%-80% 代码体积缩减、接近 100% 新应用单测覆盖和“2 周重构缩到 30-60 分钟”的落地信号。
- 影响：这说明 coding agent 的竞争点已经不只是生成质量，而是“能否被企业作为正式软件交付系统接入”。谁能同时提供模型能力、工具调用、权限边界和审计闭环，谁更可能拿下大企业开发流程的默认入口。
- 相关：[[OpenAI]]

### 2. [[Anthropic]] 的 Project Glasswing 把前沿模型安全议题推进到“漏洞处置吞吐”
- 类别：安全 / 模型能力 / 开源软件
- 时间：2026-05-22
- 摘要：Anthropic 披露 Project Glasswing 初步进展，称合作方已用 Claude Mythos Preview 在关键软件中发现超过一万条高危或严重漏洞；同时在已审查的开源漏洞样本里，真阳性率和高危确认率都表明瓶颈正在从“找漏洞”转向“验证、披露和修补”。
- 影响：这会把前沿模型竞争从“会不会攻击”进一步拉到“能否系统性重塑防守流程”。接下来最稀缺的不再只是模型能力，而是人工复核、协调披露、补丁分发和组织级响应速度。
- 相关：[[Anthropic]] / [[政策监管]] / [[算力基础设施]]

### 3. [[算力基础设施]] 的下一步是把推理负载分散到更多自研芯片与云
- 类别：算力 / 推理 / 芯片供给
- 时间：2026-05-21
- 摘要：Reuters 2026-05-21 报道，Anthropic 正在洽谈租用由 Microsoft 自研 AI 芯片驱动的服务器，以满足 Claude 服务增长带来的推理需求。
- 影响：头部模型公司正在从“抢到更多 NVIDIA GPU”转向“把不同负载拆给不同芯片和云厂商”。这既是供给弹性问题，也是成本结构问题，意味着推理时代的基础设施竞争会越来越像多供应商编排，而不是单一芯片竞赛。
- 相关：[[Anthropic]] / [[算力基础设施]]

### 4. [[政策监管]] 正从模型透明度继续外溢到劳动力冲击治理
- 类别：政策 / 劳动力 / 政府治理
- 时间：2026-05-21
- 摘要：加州州长 Gavin Newsom 于 2026-05-21 签署行政令，要求州政府围绕 AI 对劳动者、小企业和社区的潜在冲击建立预警、数据跟踪、培训和转岗支持机制。
- 影响：监管焦点已经不再只盯着模型风险和内容披露，而是在提前要求政府与企业回答“谁承担转型成本、怎样更早看到岗位变化、怎样把生产率收益分配给劳动者”。这会把企业 AI 采用从技术决策推到组织和公共政策层面。
- 相关：[[政策监管]]

### 5. [[融资并购]] 继续押注“垂直 agent + 行业知识”而不是通用聊天
- 类别：并购 / 工业 AI / 垂直 agent
- 时间：2026-05-22
- 摘要：Mistral AI 在 2026-05-22 宣布签署最终协议收购 Physics AI 创业公司 Emmi AI，目标是补强面向工程和制造场景的 physics-native AI 与工程工具调用能力。
- 影响：这说明欧洲前沿模型公司也在从通用模型竞争，转向拿下高价值工业场景中的数据、仿真和工具链入口。与其说这是一次单纯并购，不如说是 agent 往工程软件工作流深处下沉的信号。
- 相关：[[融资并购]]

## 趋势点评

过去 72 小时里，一个很清晰的结构正在形成。[[OpenAI]] 代表的是“agent 进入正式软件交付链”，[[Anthropic]] 代表的是“agent 进入高风险安全工作流”，而 [[政策监管]] 则开始追问这些系统进入真实组织之后，对岗位、培训和收益分配意味着什么。换句话说，AI 竞争已经从“模型更强”转向“模型嵌入哪些关键流程、由谁治理、怎样留下审计证据”。

与此对应，[[算力基础设施]] 也在同步变化。Anthropic 洽谈 Microsoft 自研芯片，说明推理供给将更快走向多芯片、多云、多供应商编排。资本侧则延续对垂直场景的偏好，无论是工程制造里的 Emmi AI，还是此前 Hark 这类统一入口叙事，市场都在给“默认工作流入口”和“高价值行业代理层”提前定价。

## 后续值得跟踪

- OpenAI 接下来会不会继续公布更多 Codex 企业案例，尤其是带权限控制、审计和变更管理细节的案例。
- Project Glasswing 后续公开披露的数据，是否会证明“AI 找漏洞”正在从演示能力变成新的安全基础设施。
- Anthropic 与 Microsoft 芯片合作若落地，是否会推动更多头部模型公司采用多芯片推理架构。
- 加州这类围绕 AI 劳动力冲击的治理，是否会扩散到更多州或进入企业强制披露范畴。
- Mistral 对 Emmi AI 的整合，能否把工业 AI 从问答助手推进到工程设计、仿真和制造协作流程。

# AI日记 - 2026-05-23

## 今日重点

### 1. [[OpenAI]] 把研究型突破重新拉回行业注意力中心
- 类别：模型 / 研究 / 数学
- 时间：2026-05-20
- 摘要：OpenAI 发布研究成果，称其模型给出了对离散几何中 unit distance conjecture 的反例与证明，触及一个自 1946 年以来持续约 80 年的经典问题。
- 影响：过去一周行业讨论大多围绕 agent、分发和算力，但这次事件提醒市场，前沿模型竞争仍然会周期性回到“是否能在高门槛认知任务上创造新知识”这个更高维度。对 [[OpenAI]] 而言，这不仅是研究品牌事件，也是在强化其“前沿能力上限仍在抬升”的叙事。
- 相关：[[OpenAI]]

### 2. [[Google-DeepMind]] 正把搜索入口升级为持续运行的 agent 前台
- 类别：产品 / 搜索 / agent
- 时间：2026-05-19
- 摘要：Google 在 I/O 后续说明中进一步展开 Search agents、AI 搜索框和 Antigravity 开发平台，Gemini 3.5 Flash 也成为 AI Mode 默认模型。
- 影响：这说明 Google 的核心打法已经不只是把回答做长，而是把“持续监控、主动提醒、代办执行、交易闭环”直接嵌进搜索入口。谁控制默认入口，谁就更有机会控制后续 agent 分发、订阅和商业转化。
- 相关：[[Google-DeepMind]] / [[算力基础设施]]

### 3. [[Google-DeepMind]] 的 Co-Scientist 说明多 agent 系统开始进入真实科研工作流
- 类别：模型 / 科研 / 多智能体
- 时间：2026-05-19
- 摘要：Google DeepMind 在 Nature 配套发布中介绍 Co-Scientist，并把 Hypothesis Generation 工具开放给个人研究者试用。
- 影响：这不是单一模型能力升级，而是“多 agent 生成、辩论、筛选假设”的系统化科研助手开始向实际用户开放。它代表 AI 产品从通用问答继续转向面向高价值专业工作流的结构化协作。
- 相关：[[Google-DeepMind]]

### 4. [[Anthropic]] 收购 Stainless，继续把竞争下沉到连接层
- 类别：并购 / 开发者生态 / MCP
- 时间：2026-05-18
- 摘要：Anthropic 宣布收购 Stainless，把 SDK、CLI 与 MCP server tooling 团队并入 Claude 平台。
- 影响：头部模型公司的护城河正在从模型本身延伸到“默认怎么接 API、怎么生成 SDK、怎么把 agent 连到企业工具和数据”。这类连接层资产一旦被平台内化，开发者迁移成本和生态黏性都会显著上升。
- 相关：[[Anthropic]] / [[融资并购]]

### 5. [[政策监管]] 开始把高风险 AI 的分类边界写得更具体
- 类别：政策 / 合规 / 欧盟 AI Act
- 时间：2026-05-19
- 摘要：欧盟委员会启动关于高风险 AI 系统分类指南草案的定向征询；与此同时，欧盟理事会与议会在 2026-05-07 达成的 AI 简化规则临时协议，已在 2026-05-18 更新说明中继续明确实施节奏。
- 影响：监管关注点正在从抽象原则转向“哪些系统算高风险、何时适用、透明度方案何时落地”这类部署级问题。对做 agent、企业 Copilot 和行业自动化的厂商来说，产品分类将直接影响审计、留痕和交付路径。
- 相关：[[政策监管]]

### 6. [[算力基础设施]] 正同时向“金融化 TPU 供给”与“按需租赁 Blackwell”演化
- 类别：算力 / 云基础设施 / 投融资
- 时间：2026-05-18 至 2026-05-20
- 摘要：Blackstone 与 Google 宣布成立 TPU cloud 合资公司；几乎同时，Lambda 宣布将向 Hudson River Trading 提供 1000 多套 NVIDIA Blackwell 系统的租赁访问。
- 影响：算力供给不再只是云厂商内部 CAPEX 议题，而是越来越像可以被拆分、融资、长期锁定和按吞吐出租的独立资产。[[算力基础设施]] 的竞争维度，正从“谁买到 GPU”扩展到“谁能把芯片、机房、电力、资本和租赁模式组合成长期供给”。
- 相关：[[算力基础设施]] / [[融资并购]]

### 7. [[开源模型]] 阵营开始补齐通用 agent 的公开评测基础设施
- 类别：开源 / 评测 / agent
- 时间：2026-05-18
- 摘要：Hugging Face 与 IBM Research 发布 Open Agent Leaderboard，用统一协议比较完整 agent 系统而不只比较底层模型。
- 影响：开源生态的下一个竞争点不是单纯再发一个更大的权重，而是建立大家默认认可的 agent 评测、复现和成本透明坐标系。谁定义评测框架，谁就更容易组织生态。
- 相关：[[开源模型]] / [[Anthropic]] / [[Google-DeepMind]]

## 趋势点评

最近 72 小时的关键信号比较一致：AI 竞争正在同时向上、向下和向外扩展。向上是 [[OpenAI]] 这类研究突破继续抬升“能力上限”叙事；向下是 [[Anthropic]] 把连接层工具链并入平台、[[Google-DeepMind]] 把搜索入口改造成 agent 前台；向外则是 [[算力基础设施]] 与 [[政策监管]] 开始更深地进入资本结构和实施细则。

更具体地说，行业已经不再只是比谁的模型榜单分数高，而是在比四件事：谁能证明能力上限，谁能占住默认入口，谁能控制连接器与开发者路径，谁能长期锁定供给与合规交付。这个结构下，模型公司会越来越像“研究机构 + 平台分发商 + 基础设施协调者 + 规则适配者”的混合体。

## 后续值得跟踪

- OpenAI 这次数学突破之后，是否会继续公开更多可验证的研究级成果，而不只是 benchmark 提升。
- Google Search agents 真正上线后，权限管理、日志留痕和用户撤销机制会怎么设计。
- Anthropic 并入 Stainless 后，是否会更系统地把 MCP、SDK 生成和 connector 托管产品化。
- 欧盟高风险 AI 分类指南最终版本，是否会影响企业 agent、行业 Copilot 和多工具编排系统的合规边界。
- Google x Blackstone 的 TPU cloud 与 Lambda 的 Blackwell 租赁模式，是否会让算力市场更快进入“长期容量合同 + 按工作负载出售”的阶段。
- Open Agent Leaderboard 这类框架，是否会在 2026 年下半年成为开源 agent 的事实评测标准。

# AI 日记 - 2026-05-12

## 今日重点

### 1. [[Google-DeepMind]] 继续重做 AI 搜索分发逻辑，开始更明确地把流量“导回网页”
- 类别：产品 / 搜索 / 分发
- 时间：2026-05-06
- 摘要：Google 宣布更新 AI Mode 与 AI Overviews，增加更多站外链接、站点预览、不同角度的延伸阅读，以及面向新闻订阅方的接入表单。
- 影响：这说明 Google 正在修正生成式搜索最敏感的商业矛盾之一：如果 AI 回答吃掉点击，生态就会反噬搜索本身。现在的动作不是回退 AI，而是把 AI 回答层重新设计成“更强摘要 + 更强导流”。
- 来源：[Google Blog](https://blog.google/products-and-platforms/products/search/explore-web-generative-ai-search/)
- 相关：[[Google-DeepMind]]

### 2. [[Google-DeepMind]] 把 Gemini API 的 File Search 推向 multimodal RAG 与页级引用
- 类别：模型 / 开发者平台 / RAG
- 时间：2026-05-05
- 摘要：Google 为 Gemini API File Search 增加 multimodal 支持、自定义 metadata 过滤和 page-level citations，让图文混合检索与可验证引用成为默认能力的一部分。
- 影响：这不是单点功能增强，而是在把“可验证、可落地、可治理”的 RAG 基建标准化。后续企业对 RAG 的比较重点，会越来越从模型能力转向检索结构、引用粒度与审计可用性。
- 来源：[Google Blog](https://blog.google/innovation-and-ai/technology/developers-tools/expanded-gemini-api-file-search-multimodal-rag/)
- 相关：[[Google-DeepMind]] / [[政策监管]]

### 3. [[Anthropic]] 把新增算力更快地兑现为产品供给，[[算力基础设施]] 正在直接改写前台体验
- 类别：算力 / 产品供给 / 基础设施
- 时间：2026-05-06
- 摘要：Anthropic 宣布与 SpaceX 达成新的算力合作，并同步提高 Claude Code 与 Claude API 的使用上限，包括五小时限额翻倍、取消高峰时段降额，以及提高 Opus API rate limits。
- 影响：头部模型公司的竞争，越来越不是“拿到多少 GPU”，而是“多久能把 GPU 变成用户可感知的可用性改善”。基础设施兑现效率，正在成为和模型能力同等重要的竞争变量。
- 来源：[Anthropic](https://www.anthropic.com/news/higher-limits-spacex)
- 相关：[[Anthropic]] / [[算力基础设施]]

### 4. [[政策监管]] 在欧洲继续转向“执行细则化”，一边简化高风险 AI 规则，一边推进透明度指引
- 类别：政策监管 / 合规
- 时间：2026-05-07 至 2026-05-08
- 摘要：欧盟在 5 月 7 日就 AI 规则简化方案达成政治协议，明确部分高风险系统的适用时间表；5 月 8 日，欧委会又就 AI 透明度义务草案开启征求意见，围绕 AI 交互提示、深度伪造标识与机器可读标记提出更具体要求。
- 影响：监管重点已经明显从“是否要管”转向“怎么落地、何时生效、证据链如何保存”。这会反过来推动产品团队把标识、引用、日志和审计能力前置到架构层。
- 来源：[European Commission - AI rules simplification](https://digital-strategy.ec.europa.eu/en/news/eu-agrees-simplify-ai-rules-boost-innovation-and-ban-nudification-apps-protect-citizens) / [European Commission - transparency obligations](https://digital-strategy.ec.europa.eu/en/news/commission-opens-consultation-draft-guidelines-ai-transparency-obligations)
- 相关：[[政策监管]]

### 5. [[开源模型]] 的主线继续上行，Mistral 3 把“开放权重 + 多尺寸 + 多模态 + 企业部署”绑成一组叙事
- 类别：开源 / 模型 / 部署
- 时间：近期发布
- 摘要：Mistral 发布 Mistral 3 家族，包含 3B、8B、14B 的 Ministral 系列和 675B 总参数、41B 激活参数的 Mistral Large 3，强调 Apache 2.0 开放、图像理解、多语言与从边缘到数据中心的一体化部署。
- 影响：开源阵营的竞争正在从“有没有开放权重”走向“能不能在企业环境里以可接受的成本跑起来”。模型许可、推理栈适配和硬件生态协同，正在成为开源模型商业化的核心部分。
- 来源：[Mistral AI](https://mistral.ai/news/mistral-3)
- 相关：[[开源模型]] / [[算力基础设施]]

### 6. [[融资并购]] 仍然集中流向头部平台与区域冠军，Moonshot AI 说明中国开源路线依旧有强资本承接
- 类别：融资 / 区域竞争 / 开源生态
- 时间：2026-05-07
- 摘要：Moonshot AI 完成约 20 亿美元融资、估值超过 200 亿美元，继续强化中国市场对开源权重、低成本推理和本地生态平台的押注。

- 来源：[TechCrunch](https://techcrunch.com/2026/05/07/chinas-moonshot-ai-raises-2b-at-20b-valuation-as-demand-for-open-source-ai-skyrockets/)

## 趋势点评

过去几天最值得注意的，不是某一个单点模型刷新了什么 benchmark，而是 AI 产业的五条基础主线正在同时收敛。第一条是“分发回流”，[[Google-DeepMind]] 说明搜索平台正在努力平衡生成式摘要与网页生态，不再只追求更长回答，而是重新设计点击和出处。第二条是“可验证交付”，Gemini File Search 的页级引用与 multimodal RAG，说明企业 AI 正在把引用、审计和检索结构视作核心能力，而不是附属功能。

第三条是“算力兑现”，[[Anthropic]] 的动作表明，基础设施不再只是财务或资本故事，而是直接转成 rate limit、可用性与用户体验。第四条是“监管执行化”，[[政策监管]] 已经从原则讨论进入时间表、标签义务和证据链设计阶段。第五条是“开源企业化”，[[开源模型]] 不再只卖开放姿态，而是在卖许可清晰、部署方便、硬件兼容与成本效率。把这五条线放在一起看，AI 行业已经越来越像一场系统工程竞争，而不是单一模型竞赛。

## 后续值得跟踪

- [[Google-DeepMind]] 的 AI Mode 导流改动，是否真的能缓解出版商和内容站点对生成式搜索分流的压力。
- Gemini API File Search 的页级引用与 multimodal RAG，是否会迫使其他头部平台把“可验证引用”补成标配。
- [[Anthropic]] 新增算力兑现后，Claude Code 与 Opus API 的真实稳定性是否持续改善，而不只是阶段性提额。
- 欧盟 AI 透明度义务草案最终版本，会不会进一步细化深度伪造标记、AI 交互告知和机器可读水印要求。
- [[开源模型]] 路线是否继续向“中等规模高效率模型 + 更强部署栈适配”倾斜，而不是单纯追求更大参数量。
- [[融资并购]] 是否继续沿“两极化”演进：美国头部闭源平台和中国区域开源平台分别吸走大额资金。

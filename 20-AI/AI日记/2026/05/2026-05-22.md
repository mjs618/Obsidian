# AI日记 - 2026-05-22

## 今日重点

### 1. [[Google-DeepMind]] 把 Search agents 从演示概念推进为默认信息入口
- 类别：产品 / 搜索 / agent 分发
- 时间：2026-05-20
- 摘要：Google 在 I/O 后续说明中明确，Search agents 会先以 information agents 形态上线，为用户持续监控网页、新闻、社交、金融、购物和体育等变化，并在合适时机推送综合更新；同时还把 agentic booking、Search 内生成式 UI 和 Antigravity 小应用能力接进搜索。
- 影响：这意味着搜索入口的竞争正从“谁给出更长答案”转向“谁能长期盯住任务、主动推送结果并把交易收口在自己的前台”。[[Google-DeepMind]] 正在把 [[政策监管]]、购物转化和个人信息授权问题，一起推进到 agent 入口层。
- 相关：[[Google-DeepMind]] / [[政策监管]]

### 2. [[Anthropic]] 收购 Stainless，竞争点继续从模型能力下沉到连接器与开发者入口
- 类别：并购 / 开发者生态 / agent 工具链
- 时间：2026-05-18
- 摘要：Anthropic 宣布收购 Stainless。后者长期为 Anthropic 官方 SDK 提供生成能力，也覆盖 SDK、CLI 与 MCP server tooling。Anthropic 直接把这一层并入平台，核心目标是增强 Claude 连接数据和工具的能力。
- 影响：模型公司正在把“连接谁、以什么接口连接、开发者默认用哪套 SDK/CLI/MCP”视为平台控制点。对 [[Anthropic]] 而言，这不是单纯 acqui-hire，而是在 agent 时代补齐连接层护城河。
- 相关：[[Anthropic]] / [[开源模型]]

### 3. [[Anthropic]] 与 KPMG 的大规模联盟显示企业落地已进入“全员使用 + 核心流程嵌入”阶段
- 类别：企业采用 / 服务业 / 安全
- 时间：2026-05-19
- 摘要：Anthropic 与 KPMG 宣布全球联盟，Claude 将面向 KPMG 27.6 万名员工开放，并嵌入其 Digital Gateway 平台，用于税务、法务、私募股权和网络安全等核心业务场景。
- 影响：企业 AI 的重点已经不只是“买席位”，而是把模型嵌入业务主平台、内部流程和客户交付链条。头部模型公司与咨询/审计巨头的绑定，会加速形成行业模板和交付标准。
- 相关：[[Anthropic]] / [[融资并购]]

### 4. [[政策监管]] 的落点正从原则讨论转向 AI 内容透明度执行细则
- 类别：政策 / 合规 / AI Act
- 时间：2026-05-08
- 摘要：欧盟委员会已就 AI Act 透明度义务草案开启征询，并明确从 2026-08-02 起，欧盟用户在与 AI 系统交互或接触 AI 生成/操纵内容时，需要被明确告知；同时要求机器可读标记以支持识别。
- 影响：监管焦点正在从高层原则转向具体产品实现，尤其是用户提示、内容标记、deepfake 暴露和部署方义务。对所有做 agent、搜索、内容生成的平台来说，合规将越来越像产品需求而不是法务附录。
- 相关：[[政策监管]] / [[Google-DeepMind]]

### 5. [[算力基础设施]] 的叙事继续从 GPU 扩展到 CPU、云租赁和 agent 运行栈
- 类别：算力 / 芯片 / 云基础设施
- 时间：2026-05-18 至 2026-05-20
- 摘要：NVIDIA 宣布首批 Vera CPU 已交付 Anthropic、OpenAI、OCI 和 SpaceXAI，明确把 CPU 定位为 agent 时代的关键组件；与此同时，Lambda 拿下 Hudson River Trading 合同，将出租 1000 多套 Blackwell 系统。
- 影响：算力竞争不再只是“拿到更多 GPU”，而是“谁能更稳定地提供 agent 沙箱、工具调用、长上下文状态管理和成规模租赁能力”。这对 [[OpenAI]]、[[Anthropic]] 这类高频 agent 平台都直接相关。
- 相关：[[算力基础设施]] / [[OpenAI]] / [[Anthropic]]

### 6. [[开源模型]] 侧开始补齐“如何评估通用 agent 系统”这条基础设施空白
- 类别：开源生态 / 评测 / agent
- 时间：2026-05-18
- 摘要：Hugging Face 社区文章发布 Open Agent Leaderboard，用统一协议跨六类基准测试完整 agent 系统，而非只比较底层模型，并同时展示质量与成本。
- 影响：开源阵营的下一步不只是继续堆模型，而是补齐 agent 评测、复现与成本透明化基础设施。谁能建立社区默认的评测坐标系，谁就在开源 agent 生态里获得更高的话语权。
- 相关：[[开源模型]] / [[Anthropic]] / [[Google-DeepMind]]

## 趋势点评

过去 24-72 小时最值得记录的，不是某个单点模型刷新了榜单，而是 agent 产业链的三个层面正在同时变厚。第一层是入口层，[[Google-DeepMind]] 让 Search agents、agentic booking 和 Search 内生成式 UI 进一步成形，说明“长期监控 + 主动提醒 + 交易闭环”正在替代“一次性问答”成为新的搜索竞争方式。

第二层是连接层和交付层。[[Anthropic]] 收购 Stainless、再与 KPMG 做全员级和核心流程级部署，说明模型公司的护城河正延伸到 SDK、CLI、MCP、咨询伙伴和行业模板。谁能控制连接器与交付界面，谁就更可能把模型能力沉淀为企业标准流程。

第三层是基础设施层。[[算力基础设施]] 的瓶颈继续从 GPU 扩展到 CPU、agent 沙箱、状态管理和大规模租赁供给。与此同时，[[政策监管]] 也在把透明度、告知和标记要求推进到产品细节。综合来看，AI 行业已经从“模型冲刺期”进入“agent 系统工程化期”。

## 后续值得跟踪

- Google 的 information agents 上线后，是否会形成独立的权限、日志和用户撤销机制。
- Anthropic 收购 Stainless 之后，是否会更系统地产品化 MCP、SDK 生成与连接器托管能力。
- KPMG 这类联盟模式会不会被四大和大型 IT 服务商快速复制，形成 Claude 或其他模型的行业标准交付模板。
- 欧盟 AI Act 透明度义务最终细则，会不会进一步细化到 deepfake 标记、代理式搜索回答与合成资讯推送场景。
- Vera 这类 agent CPU 与 Blackwell 云租赁，是否会让市场开始用“agent 吞吐/成本”而不是“训练集群规模”来衡量算力竞争。
- 开源 agent 评测是否会围绕 Open Agent Leaderboard 一类框架形成事实标准。

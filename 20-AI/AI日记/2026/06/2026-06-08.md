# AI日记 - 2026-06-08

## 今日重点

### 1. [[OpenAI]] 推出 Lockdown Mode，prompt injection 防护进入产品开关层
- 类别：产品安全 / agent 安全 / 数据外泄防护
- 时间：2026-06-06
- 摘要：OpenAI Help Center 更新 Lockdown Mode，说明该功能会限制可连接 Web 或外部服务的能力，以降低 prompt injection 导致的数据外泄风险；受限能力包括实时浏览、网页图片检索、Deep Research、Agent Mode、Canvas 网络访问和文件下载等。
- 影响：这不是单个安全提示，而是把“联网能力、工具调用和敏感数据”之间的风险关系做成显式产品模式。随着 agent 更常接触企业资料，[[OpenAI]] 的安全竞争重点正在从模型拒答扩展到运行时能力收缩、权限面管理和企业审计。
- 相关：[[OpenAI]] / [[政策监管]]

### 2. [[OpenAI]] “超级应用”叙事继续升温，ChatGPT 正被重新定位为统一 agent 入口
- 类别：产品战略 / 企业入口 / agent 平台
- 时间：2026-06-07
- 摘要：TechCrunch 援引 Financial Times 报道称，OpenAI 计划在未来数周推出改版 ChatGPT，将 coding tools、Codex 和 AI agents 更集中地整合为“super app”式入口。该报道仍属媒体披露，需等待官方发布验证。
- 影响：如果落地，这会把 ChatGPT 从单一聊天界面继续推向跨个人与工作场景的默认 agent 控制台。结合 Lockdown Mode，可以看到 OpenAI 同时在做两件事：扩大 ChatGPT 能做的事，同时给高敏感场景提供更明确的能力边界。
- 相关：[[OpenAI]]

### 3. 美国 AI 政策继续围绕“国家收益、监管边界和资本结构”重组
- 类别：政策 / 政府持股 / 人事变化
- 时间：2026-06-06
- 摘要：TechCrunch 报道，特朗普政府正在讨论让美国公众从 AI 公司成长中获益的股权或公共财富基金思路，并提到 OpenAI 可能成为讨论对象；同日，白宫 AI 顾问 Sriram Krishnan 将于 6 月底离任的消息也被报道。
- 影响：这说明美国 AI 政策不只是在“放松监管 vs 强监管”之间摆动，也在探索国家如何分享前沿 AI 资本收益。对 [[政策监管]] 来说，后续重点是这些讨论会停留在政治表态，还是进入 OpenAI、Anthropic、xAI 等潜在上市公司的实际股权、税收或公共基金设计。
- 相关：[[政策监管]] / [[OpenAI]] / [[融资并购]]

### 4. [[算力基础设施]] 继续进入超长合同和主权扩容阶段
- 类别：算力 / 数据中心 / 长期合同
- 时间：2026-06-05
- 摘要：SpaceX 在 SEC 文件中披露与 Google 的云服务协议，Google 将从 2026 年 10 月到 2029 年 6 月每月支付 9.2 亿美元，以获得约 11 万块 NVIDIA GPU 及相关计算组件访问权。AirTrunk 同日宣布计划到 2030 年在印度投资 300 亿美元、建设超过 5GW 数据中心容量。
- 影响：Google 原本已是 AI 算力大户，却仍通过长期合同补充外部 GPU 供给；印度也在通过政策、能源和数据中心投资争取成为 AI 基建目的地。算力竞争的单位继续从“买卡”升级为“多年合同 + 电力/土地/政策 + 区域主权供给”。
- 相关：[[Google-DeepMind]] / [[算力基础设施]]

### 5. AI 成本压力从开发工具扩散为全行业定价问题
- 类别：成本 / 开发工具 / 商业模式
- 时间：2026-06-07
- 摘要：TechCrunch 在“Tokenpocalypse”讨论中继续追踪 GitHub Copilot 计费变化。GitHub 官方已在 2026-06-01 将 Copilot 方案切换为基于 GitHub AI Credits 的用量计费，用户反馈显示高强度 agentic coding 场景的成本感知明显上升。
- 影响：这条线的重要性不在 Copilot 单一产品，而在 AI 工具开始把过去被平台补贴的推理成本显性化。[[融资并购]]、企业采购和产品定价都会被迫回答同一个问题：谁为长任务、多 agent、反复迭代和高上下文窗口买单。
- 相关：[[算力基础设施]] / [[融资并购]]

### 6. [[Anthropic]] 模型稳定性成为第三方 AI 产品的直接依赖风险
- 类别：模型供应 / 产品可靠性 / 企业集成
- 时间：2026-06-07
- 摘要：Notion 一度因 Anthropic Opus 4.7 和 4.8 模型性能下降而暂停 Notion AI 中的 Anthropic 模型访问，随后恢复。Anthropic 表示是短暂基础设施问题导致多个 Claude 模型错误率升高，问题已解决。
- 影响：这类事件说明，AI 应用层对底层模型供应商的依赖已经进入用户可见层。后续企业 AI 产品不仅要比较模型质量，也要更明确设计多模型降级、SLA、故障切换和客户沟通机制。
- 相关：[[Anthropic]]

## 趋势点评

今天的主线是“agent 扩权”和“agent 约束”同时前进。OpenAI 一边继续推进 ChatGPT 作为统一 agent 入口，一边推出 Lockdown Mode，把联网、下载、外部服务和敏感数据之间的风险收缩为可配置产品能力。这说明下一阶段产品竞争不会只看谁能调用更多工具，也会看谁能在高敏感场景里可靠地关掉一部分能力。

第二条主线是成本和算力合同继续显性化。Google 向 SpaceX 购买多年 GPU 访问权、AirTrunk 在印度押注 5GW 数据中心，说明头部公司即使拥有自研芯片和大规模云资源，也仍需要通过外部合同和区域基础设施扩容来保障供给。Copilot 的 AI Credits 争议则把同一个问题带到用户前台：推理成本不可能永远藏在订阅价里。

第三条主线是美国 AI 政策正在尝试把国家利益、资本收益和企业治理连在一起。政府持股或公共财富基金仍只是讨论与报道，但它把一个新问题放到台面：如果 AI 公司成为准基础设施级资产，国家和公众是否应分享其资本增值。这个问题会影响 OpenAI、Anthropic、xAI 等潜在上市路径，也会让 [[政策监管]] 从安全与竞争扩展到分配机制。

开源模型方面，本窗口没有看到同等级通用 open-weight 大模型新发布。今天更值得跟的是开源生态之外的两条约束：一是闭源 agent 平台的能力边界和安全模式，二是算力成本如何被转嫁到开发者、企业和终端产品。

## 后续值得跟踪

- OpenAI Lockdown Mode 是否会扩展到更细粒度的企业角色、连接器、文件和 agent 权限策略。
- OpenAI “super app”报道是否会在未来数周得到官方产品发布确认，Codex 与 ChatGPT 是否会进一步合并入口。
- 美国政府持股或公共财富基金讨论是否会进入 OpenAI、Anthropic、xAI 等公司的上市、税收或融资结构。
- Google 与 SpaceX 的算力合同是否意味着更多头部云厂商会外包一部分 GPU 供给，而不是只依赖自建数据中心。
- AirTrunk 印度 5GW 计划是否会带动更多主权 AI 基建、税收优惠和可再生能源配套政策。
- Copilot AI Credits 之后，主流 coding agent 是否会统一转向 token/credit 透明计费和企业预算控制。
- Notion/Anthropic 事件之后，AI 应用层是否会更主动披露模型供应商故障、降级策略和多模型备援。

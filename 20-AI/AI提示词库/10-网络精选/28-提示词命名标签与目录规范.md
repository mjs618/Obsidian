# 提示词命名标签与目录规范

## 定位

这页规定提示词库的文件名、标题、标签、frontmatter 和目录放置规则。目标是让提示词能被搜索、筛选、复盘和长期维护。

## 文件命名

| 类型 | 命名规则 | 示例 |
| --- | --- | --- |
| 单条提示词 | 英文短横线，描述任务 | `customer-interview-summarizer.md` |
| 方法论页面 | 中文标题，前缀编号 | `16-提示词质量评分矩阵.md` |
| 拆分模板 | 中文标题，标明对象 | `15-高质量PPT生成器拆分模板.md` |
| 索引页 | `00-索引.md` | `10-网络精选/00-索引.md` |
| 使用地图 | 固定为 `01-使用地图.md` | `AI提示词库/01-使用地图.md` |

原则：

1. 原始导入文件保留英文 slug，便于回溯来源。
2. 自建方法论和治理页使用中文标题，便于 Obsidian 阅读。
3. 不使用“超级”“万能”“终极”“爆款神器”等营销词。
4. 文件名不写模型名，模型适配写在 frontmatter 或版本记录中。

## 标题命名

| 好标题 | 问题标题 |
| --- | --- |
| `客户访谈摘要生成器` | `访谈神器` |
| `GEO文章改写拆分模板` | `超级GEO爆款改写` |
| `输出验收与交付检查清单` | `检查一下` |
| `提示词反模式与修复手册` | `坏提示词大全` |

标题要回答两个问题：

1. 它处理什么对象。
2. 它输出什么能力或结果。

## Frontmatter 标准

长期复用提示词建议使用：

```yaml
---
type: 'AI提示词'
title: '{{标题}}'
status: 'active'
quality: 'S/A/B/C/风险级'
risk: '低/中/高'
source: '{{来源}}'
source_path: '{{来源路径，可空}}'
source_url: '{{来源链接，可空}}'
created: '{{创建日期}}'
updated: '{{更新日期}}'
tags:
  - '领域/AI'
  - '类型/提示词'
  - '提示词库/自用'
  - '{{任务分类}}'
---
```

治理页建议使用：

```yaml
---
type: '方法论/规范/评估/工作流/看板'
domain: 'AI提示词'
source: '内部整理'
created: 'YYYY-MM-DD'
status: 'active'
tags:
  - '领域/AI'
  - '类型/方法论'
  - '提示词库/网络精选'
  - '提示词治理'
---
```

## 标签体系

| 标签层级 | 示例 | 用途 |
| --- | --- | --- |
| 领域 | `领域/AI` | 跨库检索。 |
| 类型 | `类型/提示词`、`类型/评估`、`类型/工作流` | 区分内容形态。 |
| 来源 | `提示词库/YaoOpenPrompts`、`提示词库/网络精选` | 回溯来源。 |
| 分类 | `提示词分类/AI工作`、`GEO`、`PPT` | 任务分类。 |
| 风险 | `风险级/法律`、`风险级/版权` | 高风险筛选。 |
| 状态 | 建议用 frontmatter `status`，不要过度用标签 | 管理 active/testing/deprecated。 |

## 状态字段

| status | 含义 | 动作 |
| --- | --- | --- |
| `active` | 可正常使用 | 保持入口。 |
| `testing` | 需要继续验证 | 不进入主推荐。 |
| `deprecated` | 已被更好模板替代 | 标注替代链接。 |
| `archived` | 只保留历史 | 不进入工作流。 |

## 质量字段

| quality | 含义 |
| --- | --- |
| `S` | 主用模板，可进入使用地图。 |
| `A` | 可用模板，需要按场景补变量。 |
| `B` | 改写后使用。 |
| `C` | 只做灵感。 |
| `风险级` | 必须有 warning 和人工复核边界。 |

## 放置规则

| 内容 | 放置位置 |
| --- | --- |
| 原始导入提示词 | 对应 `01-09` 分类目录。 |
| 网络精选可复用模板 | `10-网络精选`。 |
| 治理方法论 | `10-网络精选` 编号页。 |
| 来源许可说明 | `90-来源与维护` 或 `10-网络精选` 合规页。 |
| 项目专用改版 | 放项目笔记，不直接污染通用库。 |
| 失败案例 | [[20-AI/AI提示词库/10-网络精选/23-失败案例库与修复记录|失败案例库与修复记录]]。 |

## 新增模板入库流程

1. 按 [[20-AI/AI提示词库/10-网络精选/20-提示词卡片标准模板|提示词卡片标准模板]] 整理。
2. 按本页补文件名、frontmatter 和标签。
3. 用 [[20-AI/AI提示词库/10-网络精选/16-提示词质量评分矩阵|提示词质量评分矩阵]] 打分。
4. 补到 [[20-AI/AI提示词库/10-网络精选/10-模板元数据与测试样例集|模板元数据与测试样例集]]。
5. 若属于高风险，补到 [[20-AI/AI提示词库/10-网络精选/11-高风险模板使用边界|高风险模板使用边界]]。
6. 如果是主用模板，再补到使用地图或组合工作流。

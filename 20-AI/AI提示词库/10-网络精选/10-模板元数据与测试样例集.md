# 模板元数据与测试样例集

## 用途

这页用于补齐网络精选模板的逐条元数据。后续新增提示词时，必须至少记录：适用场景、输入变量、输出格式、风险等级和测试样例。

## 风险等级

| 等级 | 含义 | 使用建议 |
| --- | --- | --- |
| 低 | 输出主要是结构化、整理、评审、改写，风险可控 | 可直接使用。 |
| 中 | 可能影响决策、写作、产品、代码或业务判断 | 使用前补上下文，输出后人工复核。 |
| 高 | 涉及事实、法律、医疗、财务、合规、版权或外部引用 | 必须要求来源、证据、边界和人工专业审阅。 |

## S级模板测试样例

### 结构化抽取器

| 样例 | 输入 | 期望结果 |
| --- | --- | --- |
| 常规 | 一段包含姓名、公司、职位、邮箱的文本 | 输出合法 JSON，字段完整。 |
| 边界 | 文本中缺少邮箱 | 邮箱字段为 null，不编造。 |
| 异常 | 文本中出现两个手机号和两个职位 | 多候选字段用数组保留。 |

### 调试教练

| 样例 | 输入 | 期望结果 |
| --- | --- | --- |
| 常规 | 有明确报错和最近变更 | 输出 3 个假设及最小验证步骤。 |
| 边界 | 只有“程序很慢”没有日志 | 先要求补充指标和复现步骤。 |
| 异常 | 用户要求“直接给修复代码” | 仍先定位根因，不跳过验证。 |

### RAG 回答生成器

| 样例 | 输入 | 期望结果 |
| --- | --- | --- |
| 常规 | 资料中明确回答问题 | 答案后标注资料编号。 |
| 边界 | 资料只覆盖部分问题 | 明确写资料不足之处。 |
| 异常 | 用户问资料外内容 | 回答“资料不足以判断”。 |

### 最终交付质量门

| 样例 | 输入 | 期望结果 |
| --- | --- | --- |
| 常规 | 一份完整方案和验收标准 | 给出是否交付及修改清单。 |
| 边界 | 缺少目标受众 | 标记为阻塞或需确认。 |
| 异常 | 交付物含未经核实数据 | 标记为不可交付或修改后交付。 |

### 提示词改进器

| 样例 | 输入 | 期望结果 |
| --- | --- | --- |
| 常规 | “帮我写一篇文章” | 改写为包含读者、目的、结构、风格和限制的模板。 |
| 边界 | 需求只有一句话且信息不足 | 先列缺口，再给可用模板。 |
| 异常 | 用户要求保证爆款/保证转化 | 改成概率提升和测试建议，不做绝对承诺。 |

## 后续维护规则

1. 新增模板必须先进入本页补元数据。
2. 没有输入变量和输出格式的模板，不进入 S/A 级。
3. 高风险模板必须有“不足则拒答/待核实/人工审阅”规则。
4. 每个 S级模板至少保留 3 个测试样例。
5. 每次实战失败后，把失败案例补到对应模板下。

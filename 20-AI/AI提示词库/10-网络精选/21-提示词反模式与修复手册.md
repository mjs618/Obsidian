# 提示词反模式与修复手册

## 定位

这页用于识别“看起来很强、实际不稳定”的提示词。坏提示词通常不是完全没用，而是目标、上下文、输出、风险和验收缺失。

## 反模式清单

| 反模式 | 典型句式 | 问题 | 修复方式 |
| --- | --- | --- | --- |
| 角色堆叠 | 你是世界级、顶级、资深、全能专家 | 角色夸张但没有方法 | 改成具体任务能力和判断标准。 |
| 一键万能 | 输入任何内容，一键生成完美结果 | 任务边界过宽 | 拆成分析、生成、检查多个步骤。 |
| 保证结果 | 保证爆款、保证转化、保证引用 | 过度承诺 | 改成候选方案、实验指标和复盘。 |
| 无资料硬写 | 即使资料不足也要补全 | 诱导编造 | 改成资料不足则提问或标记待补充。 |
| 格式漂移 | 请详细回答 | 输出不可控 | 固定表格、JSON、章节或清单。 |
| 近似仿写 | 模仿这篇文章风格重新写 | 版权风险 | 提取结构，用新主题、新素材原创表达。 |
| 伪专业结论 | 给我法律/医疗/投资建议 | 专业误导 | 改成信息整理、问题清单和人工复核。 |
| 长文塞满 | 把所有规则写进一条提示词 | 使用成本高 | 拆成短版、标准版、完整版。 |
| 缺少验收 | 没有告诉模型什么算好 | 难以稳定改进 | 加评分标准和失败条件。 |
| 缺少版本 | 每次改完不知道哪里变了 | 无法迭代 | 增加版本记录和测试样例。 |

## 修复模式

### 1. 角色堆叠修复

坏写法：

```text
你是世界级顶级资深全能营销专家，请帮我写一篇爆款文章。
```

好写法：

```text
你是内容策略编辑。请基于我提供的资料，为目标读者生成一篇文章大纲。要求先提取事实，再提出结构，不得编造案例和数据。
```

### 2. 保证结果修复

坏写法：

```text
帮我生成一个一定会爆款的小红书标题。
```

好写法：

```text
请生成 10 个标题候选，并按点击动机、信息密度、可信度和风险给出评分。不要承诺爆款，输出适合 A/B 测试的版本。
```

### 3. 无资料硬写修复

坏写法：

```text
资料不够也没关系，你自己补充完整。
```

好写法：

```text
如果资料不足，请列出缺口并写“待补充”，不要编造事实、数据、来源或案例。
```

### 4. 近似仿写修复

坏写法：

```text
仿照这篇文章的语气和结构，写一篇差不多的。
```

好写法：

```text
请分析这篇文章的论证结构、段落功能和节奏，不复制原文表达。然后基于我的新主题和新素材，生成原创大纲。
```

### 5. 超长模板修复

坏写法：

```text
一条提示词同时完成调研、写作、排版、生成网页、检查和发布。
```

好写法：

```text
先拆成：资料整理 → 结构规划 → 内容生成 → 视觉生成 → 交付检查。每一步只接收上一步的结构化输出。
```

## 反模式审查提示词

```markdown
你是提示词反模式审查员。请检查下面的提示词是否存在不稳定、夸张、越权、侵权或难维护的问题。

提示词：
{{粘贴提示词}}

使用场景：
{{说明用途}}

请输出：
1. 命中的反模式。
2. 每个反模式的风险。
3. 必须修改的句子。
4. 修复后的写法。
5. 是否需要拆分。
6. 是否需要高风险 warning。
7. 修复后预计等级：S/A/B/C/风险级。
```

## 修复优先级

| 优先级 | 必须先修的内容 |
| --- | --- |
| P0 | 编造来源、专业误导、侵权仿写、过度承诺。 |
| P1 | 没有输入不足处理、没有输出格式、没有风险边界。 |
| P2 | 角色夸张、重复规则、过长、缺少版本记录。 |
| P3 | 语气、排版、标题和标签。 |

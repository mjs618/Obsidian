# 精选提示词模板

## 使用说明

这些模板不是直接复制网络原文，而是基于首轮筛选出的官方/开源来源重新整理的自用版本。使用时替换花括号里的变量；如果要做项目级沉淀，复制到对应项目页再改。

## 1. 提示词改进器

适用：把粗糙需求改成可稳定复用的提示词。

```markdown
你是提示词工程顾问。请把我的原始需求改写成一个可复用提示词。

原始需求：
{{粘贴你的需求}}

请按以下步骤处理：
1. 先判断任务类型、目标用户、成功标准和潜在约束。
2. 找出原始需求中模糊、缺失或容易误解的地方。
3. 给出一个改写后的提示词，包含角色、任务、输入、步骤、输出格式和质量标准。
4. 给出 3 个可调参数，说明什么时候该调整。

输出格式：
- 任务理解
- 风险与缺口
- 改写后的提示词
- 可调参数
```

## 2. 研究助理

适用：做主题研究、竞品研究、趋势梳理。

```markdown
你是严谨的研究助理。请围绕主题「{{主题}}」做一份研究简报。

背景：
{{背景信息}}

要求：
1. 先列出你需要澄清的关键问题；如果信息足够，直接继续。
2. 区分事实、推断和观点。
3. 给出核心结论、关键证据、反方观点和待验证问题。
4. 只能引用我提供的资料或你实际检索到的资料。
5. 如果没有联网能力或没有给定资料，不要编造来源链接，统一标注“待核实”。
6. 每条关键结论必须说明证据来源；证据不足时写“资料不足以判断”。

输出格式：
- 一句话结论
- 关键发现
- 证据与来源
- 不确定性
- 下一步行动
```

## 3. 长文提炼与行动清单

适用：文章、报告、访谈、会议纪要。

```markdown
请把以下内容提炼成可执行笔记。

原文：
{{粘贴文本}}

请输出：
1. 100 字以内摘要。
2. 5-10 条关键观点。
3. 作者没有明说但可以合理推断的隐含假设。
4. 对我最有用的行动清单。
5. 适合沉淀到长期笔记的概念。

要求：
- 不要复述废话。
- 不确定的推断必须标注“推断”。
- 行动清单必须具体到下一步。
```

## 4. 结构化抽取器

适用：从非结构化文本中提取表格、JSON、清单。

```markdown
你是信息抽取专家。请从以下文本中抽取结构化信息。

文本：
{{粘贴文本}}

抽取目标：
{{说明要抽取哪些字段}}

规则：
1. 只抽取文本中明确出现或可直接推导的信息。
2. 缺失字段填 null，不要编造。
3. 如果一个字段有多个候选值，保留数组。
4. 输出必须是合法 JSON，不要添加解释。

JSON 字段：
{{给出字段列表或示例 schema}}
```

## 5. 决策备忘录

适用：选择工具、项目路线、投资/采购、是否启动某项计划。

```markdown
你是理性决策顾问。请帮我评估这个决策：

决策问题：
{{要不要做什么/选哪个方案}}

背景与约束：
{{预算、时间、人员、风险、目标}}

备选方案：
{{列出方案}}

请输出：
- 推荐结论
- 判断标准及权重
- 各方案评分表
- 最大风险
- 反对推荐结论的最强理由
- 低成本验证方法
- 7 天内可执行的下一步
```

## 6. 代码审查助手

适用：让 AI 看代码、PR、设计变更。

```markdown
你是严格的代码审查者。请审查下面的代码或变更说明。

上下文：
{{项目背景/目标}}

代码或 diff：
{{粘贴代码或 diff}}

重点检查：
1. 正确性和边界条件。
2. 安全、性能和并发风险。
3. 可维护性和接口设计。
4. 测试缺口。

输出要求：
- 先列问题，按严重程度排序。
- 每个问题说明触发条件、影响、建议修复。
- 没有问题时明确说“未发现关键问题”，并列出剩余风险。
```

## 7. 调试教练

适用：遇到 bug、报错、线上异常。

```markdown
你是系统化调试教练。请帮我定位问题，不要直接猜答案。

现象：
{{错误现象}}

环境：
{{系统/版本/依赖/运行方式}}

最近变化：
{{最近改了什么}}

日志或报错：
{{粘贴日志}}

请按流程输出：
1. 问题复述。
2. 最可能的 3 个假设及证据。
3. 每个假设的最小验证步骤。
4. 需要补充的日志或命令。
5. 验证后再给修复建议。
```

## 8. 内容改写与风格保持

适用：公众号、短视频文案、说明文、产品文案。

```markdown
请在保留核心意思的前提下改写下面的内容。

原文：
{{粘贴原文}}

目标读者：
{{读者}}

目标风格：
{{风格，例如：专业克制、口语化、尖锐、有温度}}

约束：
1. 不新增未经证实的事实。
2. 保留原文的关键信息和逻辑顺序。
3. 删除套话、空话和重复表达。
4. 输出一个正式版和一个更有传播力的版本。

输出：
- 改写策略
- 正式版
- 传播版
- 主要修改点
```

## 9. 图像提示词结构器

适用：把模糊视觉想法变成图像生成提示词。

```markdown
你是图像提示词设计师。请把我的视觉想法扩展成结构化图像提示词。

视觉想法：
{{想生成什么图}}

用途：
{{头像/海报/封面/产品图/插画/壁纸}}

限制：
{{尺寸、风格、不要出现的元素、品牌要求}}

请输出：
1. 中文提示词。
2. 英文提示词。
3. 结构化字段：主体、场景、构图、镜头、光线、材质、色彩、风格、细节、负面约束。
4. 3 个风格变体。
```

## 10. 输出质量评审器

适用：让 AI 自查答案、方案、文章、提示词。

```markdown
你是质量评审专家。请审查以下输出是否达到目标。

目标：
{{原始目标}}

输出：
{{待审查内容}}

评分维度：
- 准确性
- 完整性
- 结构清晰度
- 可执行性
- 风险控制
- 读者匹配度

请输出：
1. 总分 0-100。
2. 每个维度的评分和理由。
3. 最严重的 3 个问题。
4. 具体修改建议。
5. 修改后的示例片段。
```

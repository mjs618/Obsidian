# 提示词质量评分矩阵

## 定位

这页用于判断一条提示词是否值得长期保留、直接使用、改写后使用，还是只做灵感。它补充 [[20-AI/AI提示词库/10-网络精选/09-提示词质量分级与整改清单|提示词质量分级与整改清单]]，把“优质”拆成可评分的标准。

## 100分评分表

| 维度 | 分值 | 高分标准 | 低分表现 |
| --- | ---: | --- | --- |
| 目标清晰度 | 12 | 明确任务、对象、成功标准 | 只说“帮我写/分析/优化” |
| 上下文完整度 | 12 | 给出背景、资料、限制、受众 | 让模型自行猜背景 |
| 输入变量设计 | 10 | 变量可替换、数量适中、语义明确 | 变量缺失或过多 |
| 执行过程 | 12 | 有步骤、判断规则、分支处理 | 只有角色，没有过程 |
| 输出格式 | 12 | 表格/JSON/清单/报告结构明确 | 输出随意，难复用 |
| 质量验收 | 12 | 有评分、检查清单或失败条件 | 没有验收标准 |
| 风险边界 | 12 | 有不编造、待核实、人工复核规则 | 易诱导幻觉、侵权或专业误导 |
| 可维护性 | 8 | 版本、适用场景、测试样例清楚 | 一次性口号，难迭代 |
| 模型适配 | 5 | 标明适合长文、代码、图像或RAG等场景 | 假设所有模型都一样 |
| 成本效率 | 5 | 长度合理，避免无效铺陈 | 超长、重复、角色夸张 |

## 等级判定

| 等级 | 分数 | 使用方式 |
| --- | ---: | --- |
| S级 | 85-100 | 可作为主用模板，进入使用地图或组合工作流。 |
| A级 | 70-84 | 可直接使用，但建议补测试样例和场景变量。 |
| B级 | 55-69 | 保留价值，但必须按 [[20-AI/AI提示词库/10-网络精选/17-提示词重构标准操作法\|提示词重构标准操作法]] 改写后使用。 |
| C级 | 40-54 | 只做灵感，不直接复制。 |
| 删除/归档 | 0-39 | 目标不清、风险过高、不可复用，建议归档。 |

## 红线规则

只要命中以下任一项，即使分数高，也必须标为风险级：

1. 要求模型编造来源、链接、医生/律师/专家身份、用户反馈、实验数据。
2. 承诺收益、疗效、胜诉、排名、爆款、转化率或平台推荐。
3. 要求近似复刻他人文章、网页、品牌视觉、脚本、案例或个人表达。
4. 涉及法律、医疗、财务、投资等专业结论，但没有人工复核边界。
5. 输出要求包含敏感个人信息、隐私推断或不必要的数据收集。
6. 要求绕过平台规则、越狱、规避审核或隐藏真实意图。

## 快速审计提示词

```markdown
你是提示词质量审计员。请按下面评分矩阵审计这条提示词，并给出是否值得长期保留的判断。

待审提示词：
{{粘贴提示词}}

适用场景：
{{说明用途}}

请输出：
1. 总分：0-100。
2. 各维度评分表：目标、上下文、变量、过程、格式、验收、风险、维护、模型适配、成本。
3. 是否命中红线规则。
4. 当前等级：S/A/B/C/风险级/归档。
5. 最严重的 5 个问题。
6. 改写优先级：必须改 / 建议改 / 可不改。
7. 下一版改写建议，只写结构，不直接重写全文。
```

## 典型扣分

| 问题 | 扣分建议 | 修复方向 |
| --- | ---: | --- |
| 只有角色设定，没有任务边界 | -15 | 补任务、输入、输出和验收。 |
| “世界级/顶级/专家”堆叠，但没有方法 | -10 | 删除夸张角色，补执行流程。 |
| 输出格式不固定 | -10 | 增加表格、JSON schema 或标题结构。 |
| 要求“保证效果” | -20 | 改成概率提升、实验验证和人工复核。 |
| 资料不足仍要求结论 | -20 | 增加“资料不足以判断”。 |
| 模板超过 1500 字且无拆分 | -10 | 拆成短版、标准版、完整版。 |
| 没有测试样例 | -12 | 至少补常规、边界、异常三类样例。 |

## 入库决策

| 判断 | 动作 |
| --- | --- |
| S级且低风险 | 加入使用地图或组合工作流。 |
| A级 | 加入分类索引，补元数据和测试样例。 |
| B级 | 进入整改清单，重构后再推荐。 |
| C级 | 放入灵感库，不作为主用模板。 |
| 风险级 | 加 warning、风险标签和人工复核要求。 |
| 归档 | 保留来源记录，不进入主索引。 |

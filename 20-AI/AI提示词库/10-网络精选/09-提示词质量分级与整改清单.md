# 提示词质量分级与整改清单

## 审核结论

当前提示词库已经具备可用基础：来源清楚、分类完整、可复制正文保留完整，并新增了网络精选、评估卡和组合工作流。但“优质”不能只看数量和排版，应按使用风险分层。

我的判断：

- **网络精选模板**：整体质量高，适合作为日常主用模板。
- **Yao Open Prompts 方法类/工作类/学习类**：多数可用，适合保留。
- **内容运营和 GEO 营销类**：实战感强，但存在营销化、夸大化、口号化，需要标注风险。
- **超长系统提示词**：信息完整，但日常复制成本高，需要拆成短版、标准版和完整版。

## 分级标准

具体打分使用 [[20-AI/AI提示词库/10-网络精选/16-提示词质量评分矩阵|提示词质量评分矩阵]]。本页负责分层判断，评分矩阵负责逐项扣分。

| 等级 | 定义 | 使用方式 |
| --- | --- | --- |
| S级 | 结构完整、风险控制清楚、可直接用于高价值任务 | 作为主用模板，优先放到使用地图。 |
| A级 | 可直接复用，但需要按场景补变量或资料 | 保留，使用前补上下文。 |
| B级 | 有启发价值，但过长、过泛或缺少约束 | 改写后使用。 |
| C级 | 营销话术重、夸大效果、稳定性不明 | 只做灵感，不直接复制。 |
| 风险级 | 可能诱发编造、误导、侵权、合规风险 | 加警示或移入待审区。 |

| 儿童小游戏生成器 | 可玩性强，但缺少安全边界 | 增加年龄、内容安全、家长审核和离线运行说明。 |

## C级只做灵感

| 类型 | 代表 | 原因 |
| --- | --- | --- |
| 爆款标题/爆款开头类 | 小红书标题、短视频开头、公众号爆文 | 易诱导夸大、标题党和同质化。 |
| 平台流量类 | 抖音、视频号、小红书运营模板 | 平台机制变化快，模板容易过时。 |
| 情绪文案类 | 用户心声、温暖陪伴、犀利观点 | 容易风格化过强，事实密度不足。 |
| “一键生成”类 | 网页、PPT、着陆页 | 适合演示，不适合严肃交付直接使用。 |

## 风险级提醒

| 风险 | 出现场景 | 处理方式 |
| --- | --- | --- |
| 编造事实 | 研究、企业调研、营销诊断、GEO | 强制要求来源、证据等级和“无法判断”。 |
| 法律/医疗误用 | 合同、健康报告、财务建议 | 改成信息整理，不做专业结论。 |
| 版权/仿写风险 | 爆款仿写、网页逆向、文章反编译 | 只提取结构，不复刻表达和品牌元素。 |
| 过度承诺 | 10倍增长、爆款、世界顶级、一键生成 | 改成“提高概率/生成草案/辅助分析”。 |
| 模型特定失效 | 图像、视频、代码代理、多模态 | 标注适用模型和测试日期。 |

## 优先整改清单

1. **给网络精选模板补逐条元数据**：适用场景、输入变量、输出格式、风险等级。已建立 [[20-AI/AI提示词库/10-网络精选/10-模板元数据与测试样例集|模板元数据与测试样例集]]。
2. **把超长模板拆短**：优先处理 `GEO文章改写系统`、`网页PPT生成器 V3.0`、`高质量AI PPT生成器`。已建立 [[20-AI/AI提示词库/10-网络精选/12-超长模板拆分路线|超长模板拆分路线]]，并已拆出 [[20-AI/AI提示词库/10-网络精选/13-GEO文章改写拆分模板|GEO文章改写拆分模板]]、[[20-AI/AI提示词库/10-网络精选/14-网页PPT生成器拆分模板|网页PPT生成器拆分模板]]、[[20-AI/AI提示词库/10-网络精选/15-高质量PPT生成器拆分模板|高质量PPT生成器拆分模板]]。
3. **给高风险模板加免责声明**：合同、健康、财务、法律、医疗相关内容必须提醒人工专业审阅。已建立 [[20-AI/AI提示词库/10-网络精选/11-高风险模板使用边界|高风险模板使用边界]]，并已给合同、健康、医疗科普、个人理财模板加 warning。
4. **给研究类模板加“无资料不引用”规则**：避免模型假造来源链接。
5. **把 C级内容运营模板降级为灵感库**：保留结构，不默认进入主用工作流。
6. **建立测试样例集**：每个 S级模板至少 3 个样例：常规、边界、异常。
7. **建立重构标准**：B级/C级/风险级模板按 [[20-AI/AI提示词库/10-网络精选/17-提示词重构标准操作法|提示词重构标准操作法]] 补变量、流程、输出格式、风险边界和测试样例。
8. **建立实战复盘闭环**：重要任务按 [[20-AI/AI提示词库/10-网络精选/18-提示词实战工作流与复盘系统|提示词实战工作流与复盘系统]] 做小样测试、评分和失败案例沉淀。

## 我的使用建议

日常优先用 S级和 A级。B级适合改写后使用。C级适合做灵感，不适合直接复制给模型处理严肃任务。风险级不应该删除，但必须清楚标注边界，因为它们在特定场景有价值，但误用成本高。

# 来源许可与引用合规规范

## 定位

这页用于管理提示词来源、许可、改写说明和引用边界。它不是法律意见，而是提示词库内部的来源记录和风险控制规范。

## 来源分级

| 来源类型 | 可用性 | 处理方式 |
| --- | --- | --- |
| 官方文档 | 高 | 可引用方法和原则，保留链接和日期。 |
| 开源仓库 | 高/中 | 检查许可证，保留仓库、路径、作者和版本。 |
| 明确许可的提示词库 | 中/高 | 保留许可说明和改写记录。 |
| 社区帖子/博客 | 中 | 只提炼结构，避免照搬正文。 |
| 付费课程/闭源资料 | 低 | 不直接收录原文，只记录个人理解。 |
| 来源不明截图 | 低 | 不进入主库，只做临时灵感。 |

## 入库必须记录

| 字段 | 说明 |
| --- | --- |
| `source` | 来源名称。 |
| `source_url` | 来源链接，没有则为空。 |
| `source_path` | 本地或仓库路径。 |
| `license` | 许可证或使用说明，未知写 `unknown`。 |
| `imported/created` | 导入或创建日期。 |
| `modified` | 是否做过改写。 |
| `attribution` | 是否需要署名。 |

## 改写说明

如果不是原文收录，而是整理、改写、拆分或融合，应在笔记中写明：

```markdown
## 来源与改写说明

- 来源：
- 许可：
- 本页处理方式：索引 / 摘要 / 改写 / 拆分 / 融合 / 自建
- 是否保留原文：
- 是否加入自定义风险边界：
- 最近更新：
```

## 不同处理方式

| 处理方式 | 含义 | 风险 |
| --- | --- | --- |
| 索引 | 只记录链接和用途 | 低 |
| 摘要 | 用自己的话概括 | 中 |
| 改写 | 转成自用模板 | 中 |
| 拆分 | 把超长模板拆成多个模板 | 中 |
| 融合 | 多来源合成新模板 | 中/高 |
| 原文收录 | 保留完整提示词正文 | 取决于许可 |

## 引用边界

1. 不把来源不明内容包装成自建原创。
2. 不把社区提示词当成官方最佳实践。
3. 不复制付费内容、闭源课程或不明来源截图。
4. 改写后要记录“改了什么”，尤其是风险边界和变量结构。
5. 对外分享时保留必要署名和许可说明。

## 高风险来源

| 来源问题 | 处理 |
| --- | --- |
| 无作者、无链接、无许可 | 不进入主库。 |
| 明显越狱或规避审核 | 不收录。 |
| 承诺收益、爆款或疗效 | 只做反模式案例。 |
| 近似复制他人付费模板 | 不收录原文。 |
| 含隐私或个人数据 | 脱敏后再判断是否保留。 |

## 来源审查提示词

```markdown
你是提示词来源审查员。请判断下面这条提示词是否适合进入我的提示词库。

提示词或摘要：
{{内容}}

来源信息：
{{来源链接、作者、许可证、路径}}

我的处理方式：
{{索引/摘要/改写/拆分/融合/原文收录}}

请输出：
1. 来源可信度：高/中/低/未知。
2. 许可风险：低/中/高/未知。
3. 是否适合进入主库。
4. 是否只能做灵感或反模式案例。
5. 必须保留的署名和来源信息。
6. 建议 frontmatter 字段。
7. 需要加入的风险说明。
```

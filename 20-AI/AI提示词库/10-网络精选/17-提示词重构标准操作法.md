# 提示词重构标准操作法

## 定位

这页用于把一条“能用但不稳定”的提示词改造成长期可维护模板。它适合处理 B级、C级、超长、风险级提示词。

## 重构总原则

1. 保留有效结构，删除夸张角色和重复修饰。
2. 先明确任务边界，再写角色设定。
3. 变量必须可替换，不能把一次性场景写死。
4. 风险控制写进 Prompt 正文，而不是只写在笔记说明里。
5. 每次重构都要补测试样例，否则无法判断是否真的变好。

## 七步重构法

| 步骤 | 动作 | 产物 |
| --- | --- | --- |
| 1. 识别任务 | 说明它到底解决什么问题 | 一句话用途 |
| 2. 提取变量 | 把固定信息替换成 `{{变量}}` | 变量清单 |
| 3. 拆分流程 | 把大任务拆成判断、执行、检查 | 步骤清单 |
| 4. 固定输出 | 指定表格、JSON、报告或清单 | 输出格式 |
| 5. 补风险边界 | 加不编造、待核实、人工复核 | 安全规则 |
| 6. 增加验收 | 写通过标准和失败条件 | 验收清单 |
| 7. 建测试样例 | 常规、边界、异常各一条 | 测试集 |

## 推荐模板骨架

```markdown
你是 {{角色}}。你的任务是 {{任务目标}}。

输入：
- {{变量一}}：
- {{变量二}}：
- {{变量三}}：

工作规则：
1. 只能基于用户提供的信息和明确可验证的资料回答。
2. 如果资料不足，写“资料不足以判断”，不要编造。
3. 不得承诺无法保证的结果。
4. 涉及高风险内容时，列出需人工复核的部分。

执行步骤：
1. 先判断输入是否足够；不足则提出澄清问题。
2. 提取关键信息。
3. 按任务目标生成结果。
4. 自检输出是否满足格式和质量要求。

输出格式：
## 结论
...

## 依据
...

## 结果
...

## 不确定性
...

## 下一步
...
```

## 变量命名规范

| 类型 | 推荐变量 | 不推荐 |
| --- | --- | --- |
| 任务 | `{{任务目标}}`、`{{成功标准}}` | `{{内容}}` |
| 对象 | `{{目标读者}}`、`{{使用对象}}` | `{{人群}}` |
| 资料 | `{{原始资料}}`、`{{证据材料}}` | `{{信息}}` |
| 风格 | `{{语气风格}}`、`{{禁用风格}}` | `{{高级感}}` |
| 输出 | `{{输出格式}}`、`{{字段定义}}` | `{{结果}}` |
| 限制 | `{{禁止事项}}`、`{{合规边界}}` | `{{注意}}` |

## 常见问题与改法

| 原问题 | 风险 | 改法 |
| --- | --- | --- |
| “你是世界级专家” | 空泛，不提升质量 | 改成具体能力和判断标准。 |
| “帮我生成爆款” | 过度承诺 | 改成生成候选方案和测试指标。 |
| “参考这篇文章仿写” | 版权风险 | 改成提取结构，使用新素材原创表达。 |
| “给我专业建议” | 法律/医疗/财务误用 | 改成信息整理和问题清单。 |
| “输出越详细越好” | 冗长低效 | 指定篇幅、结构和优先级。 |
| “如果没有资料也要补全” | 诱导幻觉 | 改成缺失填 null 或待补充。 |

## 重构提示词

```markdown
你是提示词重构专家。请把下面的提示词改造成可长期复用的结构化模板。

原提示词：
{{粘贴原提示词}}

使用场景：
{{说明场景}}

目标用户：
{{说明谁会用}}

请按以下步骤输出：
1. 一句话说明原提示词的真实用途。
2. 列出原提示词的主要问题，最多 8 条。
3. 提取可复用变量，形成变量清单。
4. 判断风险等级，并给出必须保留的边界规则。
5. 给出新版提示词，包含角色、任务、输入、规则、步骤、输出格式、验收标准。
6. 给出 3 个测试样例：常规、边界、异常。
7. 给出版本备注：本次改了什么、仍有什么限制。
```

## 重构验收清单

| 检查项 | 通过标准 |
| --- | --- |
| 是否有明确任务目标 | 一句话能说明用途。 |
| 是否有变量清单 | 用户知道要填什么。 |
| 是否有输入不足处理 | 会先问问题或标记资料不足。 |
| 是否有固定输出格式 | 结果可复制到下一步。 |
| 是否有风险边界 | 不编造、不越权、不承诺结果。 |
| 是否有测试样例 | 至少常规、边界、异常三类。 |
| 是否长度合理 | 日常版不超过 800-1200 字，超出应拆分。 |

## 版本记录建议

每条重构后的提示词建议在笔记底部保留：

```markdown
## 版本记录

| 版本 | 日期 | 修改点 | 验证样例 | 结论 |
| --- | --- | --- | --- | --- |
| v1.0 | 2026-05-09 | 初版结构化 | 常规/边界/异常 | 可用 |
```

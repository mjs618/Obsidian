# 高风险模板使用边界

## 定位

这页用于管理容易被误用的提示词。高风险模板不是不能用，而是不能直接当成专业结论使用。它们只能用于信息整理、草案生成、教育科普、问题清单和人工审核前的准备工作。

## 通用高风险提示词补丁

如果某个模板涉及法律、医疗、财务、投资、合规、版权、事实核查，应在 Prompt 中补入：

```markdown
安全边界：
1. 你只能做信息整理、草案生成和风险提示，不能提供专业结论。
2. 如果资料不足，请明确写“资料不足以判断”，不要编造。
3. 不得承诺收益、疗效、法律结果或平台效果。
4. 涉及重大决策时，必须建议用户咨询具备资质的专业人士。
5. 输出中必须列出不确定性和需要人工复核的部分。
```

## 审核清单

| 检查项 | 通过标准 |
| --- | --- |
| 是否声明非专业意见 | 明确写明不是法律/医疗/财务建议。 |
| 是否限制事实来源 | 要求基于给定资料或可靠来源，不编造。 |
| 是否避免承诺结果 | 不承诺收益、疗效、胜诉、转化、爆款。 |
| 是否有人审要求 | 重大用途必须人工专业审阅。 |
| 是否列不确定性 | 输出必须列出不确定、待核实、需补充信息。 |

# 提示词资产维护看板

## 定位

这页用于定期维护提示词库。提示词会过期：模型能力变化、平台规则变化、业务场景变化、失败案例累积，都会让原本好用的模板变差。

## 维护节奏

| 周期 | 动作 | 目标 |
| --- | --- | --- |
| 每次重要使用后 | 记录复盘 | 把失败和有效改法沉淀下来。 |
| 每周 | 检查新增模板 | 补卡片、元数据、风险标签和测试样例。 |
| 每月 | 审查 S/A 级模板 | 降级失效模板，升级稳定模板。 |
| 每季度 | 检查平台/模型适配 | 更新模型策略、工具限制和风险边界。 |

## 升级与降级规则

| 情况 | 动作 |
| --- | --- |
| 连续 3 次真实任务表现稳定 | 可从 A 升 S。 |
| 常规样例通过但边界样例失败 | 保持 A 或降 B。 |
| 出现高风险失败 | 立即标风险级并加 warning。 |
| 过长导致使用成本高 | 拆分后再评级。 |
| 来源不清或许可不明 | 不进入主推荐。 |
| 只适合某次项目 | 项目归档，不进公共库。 |

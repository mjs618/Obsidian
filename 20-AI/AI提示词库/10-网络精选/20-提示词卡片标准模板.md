# 提示词卡片标准模板

## 定位

一条提示词如果要长期复用，不能只保存 Prompt 正文。它应该是一张“提示词卡片”：知道它从哪里来、适合什么场景、怎么填变量、风险在哪里、如何测试、失败后怎么改。

## 标准卡片结构

```markdown
---
type: 'AI提示词'
title: '{{提示词名称}}'
status: 'active'
quality: 'S/A/B/C/风险级'
risk: '低/中/高'
source: '{{来源}}'
source_url: '{{来源链接，可空}}'
created: '{{创建日期}}'
updated: '{{更新日期}}'
tags:
  - '领域/AI'

  - '提示词库/自用'

## 必填字段

| 字段 | 为什么必须有 |
| --- | --- |
| 一句话用途 | 防止模板用途漂移。 |
| 适用场景 | 帮助选择，不让所有任务都套同一条。 |
| 不适用场景 | 明确边界，比只写适用更重要。 |
| 输入变量 | 让提示词可复用。 |
| 输出格式 | 让结果可接入下一步。 |
| 质量标准 | 判断结果是否达标。 |
| 风险边界 | 降低编造、侵权和专业误导。 |
| 测试样例 | 验证模板是否稳定。 |

## 命名规范

| 类型 | 推荐命名 | 不推荐 |
| --- | --- | --- |
| 生成类 | `客户访谈摘要生成器` | `超级访谈神器` |
| 评审类 | `PRD评审员` | `产品大神` |
| 抽取类 | `发票字段抽取器` | `信息整理助手` |
| 工作流类 | `研究到报告工作流` | `万能研究专家` |
| 高风险类 | `合同草案辅助器` | `合同生成律师` |

## 质量字段建议

| 字段 | 可选值 |
| --- | --- |
| `quality` | `S`、`A`、`B`、`C`、`风险级` |
| `risk` | `低`、`中`、`高` |
| `status` | `active`、`testing`、`deprecated`、`archived` |
| `source` | `自建`、`网络精选改写`、`Yao Open Prompts`、`官方文档` |

## 入库前检查

1. 是否能一句话说清用途。
2. 是否有明确输入变量。
3. 是否有固定输出格式。
4. 是否有“不适用场景”。
5. 是否有风险边界。
6. 是否至少有 3 个测试样例。
7. 是否能被 [[20-AI/AI提示词库/10-网络精选/16-提示词质量评分矩阵|提示词质量评分矩阵]] 打到 70 分以上。

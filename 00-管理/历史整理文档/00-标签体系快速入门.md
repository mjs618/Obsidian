# 🚀 标签体系快速入门

> 5 分钟开始使用新的标签体系

---

## ✅ 第一步：了解标签结构

新标签体系采用**四个维度**的分类方法：

```
1. 领域维度：#领域/技术  #领域/AI  #领域/工作  #领域/知识  #领域/思维  #领域/生活
2. 类型维度：#类型/笔记  #类型/文章  #类型/项目  #类型/模板  #类型/汇总  #类型/资源
3. 状态维度：#状态/进行中  #状态/待处理  #状态/已完成  #状态/归档
4. 优先级：   #重要  #待复习  #待整理  #灵感
```

---

## 🎯 第二步：在新笔记中使用

### 最简单的标签组合

创建新笔记时，只需添加**2-3 个标签**：

```markdown
# 示例：技术学习笔记
#领域/技术 #类型/笔记

# 示例：AI 文章阅读
#领域/AI #类型/文章

# 示例：工作总结
#领域/工作 #类型/汇总
```

### 使用模板自动添加

所有模板已经更新，使用模板时会自动包含推荐标签：
- 📚 学习笔记 → `#领域/技术 #类型/笔记 #状态/进行中`
- 📋 会议记录 → `#领域/工作 #类型/汇总 #状态/进行中`
- 💡 灵感卡片 → `#领域/思维 #类型/卡片 #灵感`
- 🚀 项目规划 → `#领域/工作 #类型/项目 #重要`

---

## 📱 第三步：在 Obsidian 中查看标签

### 启用标签面板
1. 右键点击右侧边栏
2. 确保勾选"标签"
3. 标签面板会显示所有标签的层级结构

### 使用标签搜索
在搜索框中输入：
```
#领域/AI           # 搜索所有 AI 相关内容
#类型/资源         # 搜索所有参考资料
#重要              # 搜索所有重要内容
#领域/技术 #类型/笔记  # 搜索技术笔记（同时满足）
```

---

## 🔄 第四步：逐步整理旧笔记

### 不要一次性整理！

**推荐策略**：
1. **新笔记立即用**：从今天开始，所有新笔记使用新标签
2. **旧笔记渐进式**：编辑旧笔记时顺便添加标签
3. **高优先级优先**：先给重要笔记添加标签

### 批量添加技巧

1. 使用全局搜索找到某类笔记
2. 批量打开需要添加标签的笔记
3. 在 YAML frontmatter 中添加 tags

## 🎨 进阶用法

### 组合查询

在搜索中使用：
```
#领域/技术 -#状态/归档    # 技术内容但排除归档
#重要 AND #类型/资源      # 重要的参考资料
```

### Dataview 查询

如果你安装了 Dataview 插件：
```dataview
TABLE file.name, file.mtime
FROM #领域/AI AND #类型/文章
SORT file.mtime DESC
LIMIT 10
```

## ⚠️ 常见错误

### ❌ 错误做法
- 给一篇笔记添加 20+ 标签
- 创建过于细粒度的标签（如 `#领域/技术/编程/Python/库/Pandas`）
- 混用不同命名风格（`#技术` vs `#领域/技术`）

### ✅ 正确做法
- 每篇笔记 3-5 个标签
- 使用预设的标签层级
- 保持一致的命名风格

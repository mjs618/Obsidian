## 🎯 文件夹命名规则

### 数字前缀法（推荐）

```
00-管理/
10-技术笔记/
20-AI 学习/
30-工作/
...
```

**优点**：
- ✅ 文件夹按重要性排序
- ✅ 固定顺序，便于查找
- ✅ 易于扩展新类别

### 表情符号法

```
📊 管理/
💻 技术笔记/
🤖 AI 学习/
💼 工作/
```

**优点**：
- ✅ 视觉识别度高
- ✅ 美观有趣

**缺点**：
- ❌ 可能在某些系统中显示问题
- ❌ 搜索时不便

### 纯文字法

```
管理/
技术笔记/
AI 学习/
工作/
```

**优点**：
- ✅ 简洁清晰
- ✅ 兼容性好

**缺点**：
- ❌ 无法体现优先级

## 📁 文件夹深度建议

### 推荐：2-3 层深度

```
✅ 好：
50-生活/
├── 日记/
│   └── 2026/
│       └── 2026-01.md
└── 周记/
    └── 2026-W01-周总结.md

❌ 不好（太深）：
生活/
└── 日记/
    └── 2026/
        └── 第一季度/
            └── 1 月/
                └── 第 1 周/
                    └── 2026-01-01.md
```

**原因**：
- 过深的文件夹难以导航
- 配合标签使用，不需要太细的分类
- 搜索和筛选更高效

## 🔀 文件夹 vs 标签

### 使用文件夹的场景

```
✅ 粗粒度分类
✅ 物理隔离（不同设备同步）
✅ 权限管理
✅ 备份策略
```

### 使用标签的场景

```
✅ 多维度分类
✅ 跨文件夹检索
✅ 状态跟踪
✅ 优先级标记
```

### 最佳实践

```
文件夹 = 是什么（What）
标签 = 怎么找（How）

例如：
📁 10-技术笔记/Python/脚本.py
  #领域/技术 #类型/笔记 #待复习
```

## 🚀 迁移指南

### 从现有结构迁移

**步骤 1：评估现状**
```
1. 列出所有文件夹
2. 识别重复内容
3. 找出未分类笔记
```

**步骤 2：设计新结构**
```
1. 参考推荐结构
2. 根据需求调整
3. 保持简洁
```

**步骤 3：渐进迁移**
```
1. 先迁移重要笔记
2. 旧笔记逐步整理
3. 新笔记直接使用新结构
```

**步骤 4：添加标签**
```
1. 按文件夹批量添加标签
2. 使用 Tag Wrangler 统一命名
3. 检查标签完整性
```

## 💡 特殊文件夹说明

### 00-管理/
存放管理系统文档，如标签体系、配置说明等。
- 特点：高频率访问
- 标签：`#领域/知识 #重要`

### 99-归档/
存放历史内容，保持主工作区清爽。
- 特点：低频率访问
- 标签：`#状态/归档`

临时存放新笔记，定期清理。
- 特点：过渡性质
- 标签：`#待整理`
- **重要**：每周清理一次！

## 📊 文件夹统计

使用 Dataview 查看文件夹使用情况：

```dataview
TABLE length(rows) AS "笔记数"
FROM 
GROUP BY file.folder
SORT length(rows) DESC
```

```dataview
TABLE WITHOUT ID
    file.folder AS "文件夹",
    length(rows) AS "笔记数"
FROM 
GROUP BY file.folder
ORDER BY length(rows) DESC
```

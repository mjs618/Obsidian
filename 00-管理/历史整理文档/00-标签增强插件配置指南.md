# 🔌 标签增强插件配置指南

> 让你的标签体系更智能、更自动化

## 📦 必装插件推荐

### 1. Templater - 模板自动化

**作用**：自动根据笔记位置/内容添加标签

**安装步骤**：
1. 设置 → 第三方插件 → 浏览
2. 搜索 "Templater"
3. 点击安装并启用

**配置方法**：

创建文件夹 `Templates/Templater/`，然后创建以下模板：

#### ① 自动根据文件夹添加标签

创建 `自动标签.md`：
```javascript
<%*
// 根据文件夹路径自动添加标签
const folder = tp.file.folder(true);
let tags = [];

if (folder.includes("技术笔记")) {
    tags = ["#领域/技术", "#类型/笔记"];
} else if (folder.includes("AI 学习")) {
    tags = ["#领域/AI", "#类型/文章"];
} else if (folder.includes("工作") || folder.includes("项目")) {
    tags = ["#领域/工作", "#类型/项目"];
} else if (folder.includes("知识库")) {
    tags = ["#领域/知识", "#类型/笔记", "#重要"];
} else if (folder.includes("思维笔记")) {
    tags = ["#领域/思维", "#类型/笔记"];
} else if (folder.includes("模版")) {
    tags = ["#类型/模板"];
} else {
    tags = ["#待整理"];
}

// 添加状态标签
const status = await tp.system.prompt("选择状态", ["进行中", "待处理", "已完成", "草稿"]);
tags.push(`#状态/${status}`);

// 写入 frontmatter
tR += `---
created: ${tp.date.now("YYYY-MM-DD HH:mm")}
tags: [${tags.join(", ")}]
---

`;
%>
```

**使用方法**：
- 新建笔记时运行此模板
- 会自动根据所在文件夹添加对应领域标签
- 弹窗选择状态标签

### 2. Dataview - 标签可视化查询

**作用**：用代码查询和展示标签内容

**安装步骤**：
1. 设置 → 第三方插件 → 浏览
2. 搜索 "Dataview"
3. 点击安装并启用

**配置方法**：

创建 `标签仪表盘.md`（见下方模板）

**常用查询示例**：

```dataview
TABLE file.name AS "笔记名称", file.mtime AS "最后修改"
FROM #领域/AI
WHERE !contains(file.folder, "归档")
SORT file.mtime DESC
LIMIT 20
```

```dataview
TABLE file.name AS "资源", file.ctime AS "创建时间"
FROM #类型/资源 AND #重要
SORT file.ctime DESC
```

```dataview
TASK
FROM #状态/进行中
WHERE !completed
SORT priority DESC
```

### 3. QuickAdd - 快速添加标签

**作用**：一键添加预设标签组合

**安装步骤**：
1. 设置 → 第三方插件 → 浏览
2. 搜索 "QuickAdd"
3. 点击安装并启用

**配置方法**：

设置 → QuickAdd → 添加新 Macro

#### Macro 1: 添加技术标签
```javascript
// 名称：Add Tech Tags
module.exports = async (params) => {
    const { app, vault, file } = params;
    const editor = app.workspace.activeEditor;
    
    if (!editor) return;
    
    // 在 frontmatter 中添加标签
    const tags = "#领域/技术 #类型/笔记";
    editor.replaceSelection(`\n${tags}\n`);
};
```

#### Macro 2: 添加重要标记
```javascript
// 名称：Add Important Tag
module.exports = async (params) => {
    const { app } = params;
    const editor = app.workspace.activeEditor;
    
    if (!editor) return;
    
    editor.replaceSelection(` #重要`);
};
```

**使用方法**：
- 设置快捷键触发 Macro
- 或在命令面板中运行

---

### 4. Tag Wrangler - 标签批量管理

**作用**：重命名、合并、清理标签

**安装步骤**：
1. 设置 → 第三方插件 → 浏览
2. 搜索 "Tag Wrangler"
3. 点击安装并启用

**功能说明**：

**重命名标签**：
- 右键点击标签面板中的标签
- 选择 "Rename tag"
- 输入新名称，自动更新所有引用

**合并标签**：
- 使用搜索找到所有使用旧标签的笔记
- 批量替换为新标签

**清理未使用标签**：
- 定期检查标签面板
- 删除空标签

## 🎯 插件组合使用场景

### 场景 1: 新建技术笔记

1. 使用 **Templater** 创建笔记
   - 自动添加 `#领域/技术 #类型/笔记`
   - 根据文件夹自动分类

2. 如果需要标记为重要
   - 运行 **QuickAdd** Macro
   - 添加 `#重要` 标签

3. 后续查看
   - 使用 **Dataview** 查询所有技术笔记
   - 在标签仪表盘查看

---

### 场景 2: 整理旧笔记

1. 使用 **标签搜索** 找到未分类笔记
   - 搜索：`-#领域/*`

2. 批量打开笔记

3. 手动或使用 **QuickAdd** 添加标签

4. 使用 **Tag Wrangler** 清理重复标签

---

### 场景 3: 标签维护

1. 每月运行一次标签检查

2. 使用 **Dataview** 查询：
```dataview
TABLE length(file.tags) AS "标签数", file.name
FROM !#领域/*
WHERE file.name != "00-标签体系使用指南"
SORT length(file.tags) ASC
```

3. 找到未添加领域标签的笔记

4. 逐一添加或批量处理

## ⚙️ 插件配置建议

### Templater 配置
```
Template folder location: Templates/Templater/
Trigger Templater on new file creation: 开启
```

### Dataview 配置
```
Enable Inline Queries: 开启
Enable JavaScript Queries: 开启
Render Null as: `[empty]`
```

### QuickAdd 配置
为常用 Macro 设置快捷键：
- 添加技术标签：`Ctrl+Alt+T`
- 添加重要标记：`Ctrl+Alt+I`
- 添加 AI 标签：`Ctrl+Alt+A`

### Tag Wrangler 配置
```
Confirm tag renaming: 开启
Confirm tag merging: 开启
```

## 💡 高级技巧

### 1. 条件标签
```javascript
<%*
const hour = new Date().getHours();
let timeTag = "";

if (hour >= 5 && hour < 12) {
    timeTag = "#时间/早晨";
} else if (hour >= 12 && hour < 18) {
    timeTag = "#时间/下午";
} else {
    timeTag = "#时间/晚上";
}

tR += timeTag;
%>
```

### 2. 自动关联标签
```javascript
<%*
// 如果包含特定关键词，自动添加标签
const content = await app.vault.read(app.vault.getAbstractFileByPath(tp.file.path));
if (content.includes("Python")) {
    tR += " #技术/Python";
}
if (content.includes("机器学习") || content.includes("AI")) {
    tR += " #领域/AI";
}
%>
```

## ⚠️ 注意事项

1. **不要过度自动化**
   - 保持手动控制的能力
   - 自动化应该是辅助，不是替代

2. **定期备份配置**
   - 备份 `.obsidian` 文件夹
   - 使用 Git 版本控制

3. **测试后再使用**
   - 新模板先在测试笔记中运行
   - 确认无误后再应用到正式笔记

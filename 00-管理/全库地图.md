# 全库地图

这页对应 Dusk Vault 的 Map of Content 思路：不是列出所有文件，而是解释“从一个问题出发应该去哪里”。

新的 Dusk 风格入口见 [[HUB/Map]]。

## 四层结构

```mermaid
flowchart TD
    Hub[HUB 日常入口] --> PARA[行动系统]
    Hub --> ZETA[知识系统]
    Hub --> Daily[周期复盘]
    Hub --> System[系统治理]

    PARA --> Projects[30-工作 项目]
    PARA --> Areas[持续领域: 技术/AI/生活/思维]
    PARA --> Resources[70-数据资料/80-Clippings]
    PARA --> Archive[99-归档]

    ZETA --> Fleeting[未分类/灵感/临时记录]
    ZETA --> Literature[剪藏/来源/学习资料]
    ZETA --> Permanent[主题 MOC/原则卡片/项目复盘]

    Daily --> Weekly[周报]
    Daily --> Review[定期维护清单]
    System --> Rules[治理规范]
    System --> Templates[模板]
    System --> Tasks[任务邮箱]
```

## 成熟路径

```mermaid
flowchart LR
    Capture[收集] --> Triage[分拣]
    Triage --> Organize[整理]
    Organize --> Link[链接]
    Link --> Distill[提炼]
    Distill --> Reuse[复用]
```

每篇笔记不必一开始就完整，但应该知道自己处在哪个阶段。

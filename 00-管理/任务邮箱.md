## 任务流

```mermaid
flowchart TD
    Find[发现页面问题] --> Add[加入任务邮箱]
    Add --> Pick[每周选 1-2 项]
    Pick --> Improve[补结构/链接/判断]
    Improve --> Done{是否可复用}
    Done -->|是| Mark[标记重要或链接 MOC]
    Done -->|否| Next[保留下一步]
```

## 使用规则

- 这里只放“页面级任务”，不放零散生活待办。
- 每周处理 1-2 项即可，不追求一次清空。
- 处理完后更新页面本身，再从这里移除或改状态。

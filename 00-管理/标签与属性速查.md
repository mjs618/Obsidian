# 标签与属性速查

## template_type

`template_type` 只用于模板和自动化兼容，不替代 `type`。

| template_type | 用途 |
| --- | --- |
| `project_family` / `project_note` | 兼容项目看板、QuickAdd 和旧 Dataview 查询 |
| `area_family` / `area_note` / `area_note_sub` | 兼容 PARA Areas 查询 |
| `meeting` | 兼容日、周、月模板中的会议查询 |
| `documentation_note` / `workstation_note` | 兼容资料和工作记录连接选择 |
| `fleeting_note` / `literature_note` / `permanent_note` | 标识 ZETA 加工阶段 |
| `contact` / `sticky_note` | 标识联系人和临时便签模板 |

## AI 提示词库兼容规则

`20-AI/AI提示词库` 是受控资产区，不按普通笔记逐条改写。这里可以保留来源、许可、版本、分类和测试字段，用来追踪外部 Prompt 的来源和复用风险。

| 字段或标签 | 使用边界 |
| --- | --- |
| `type: AI提示词` | 只用于 `20-AI/AI提示词库`，普通 AI 笔记仍使用 `笔记`、`资源`、`汇总` 或 `日记` |
| `type: AI提示词合集` | 只用于提示词库中的集合型资产、组合包或分类页 |
| `domain: AI提示词` | 只用于提示词库资产区，避免和普通 AI 观察、学习资料混在同一治理口径里 |
| `status: active` | 兼容提示词资产的导入状态，对应治理含义“可用/进行中” |
| `status: deprecated` | 对应治理含义“已废弃/归档”，保留原文但不再推荐使用 |
| `status: review` | 对应治理含义“待整理/待审查” |
| `类型/提示词` | 只用于可复制复用的 Prompt 资产 |
| `提示词库/*` | 来源或资产集合，例如 `提示词库/YaoOpenPrompts`、`提示词库/网络精选` |
| `提示词分类/*` | 提示词内部分类；不要扩散到普通 AI 日记或学习笔记 |

提示词资产可以额外保留 `category`、`subcategory`、`source`、`license`、`quality`、`risk` 等字段。网络精选中已经存在的 `拆分模板`、`评估表`、`维护看板`、`验收清单` 等细分 `type` 可以视为提示词库内部分类，不作为全库通用类型扩散。若某个细标签只出现一次，优先考虑改为 `category/subcategory` 字段或正文链接，不继续扩展全库标签体系。

## 标签原则

- 每篇正式笔记至少一个 `领域/*` 和一个 `类型/*`。
- 自动化模板中保留 `project/*`、`area/*`、`contact/*` 等兼容标签，用于 QuickAdd、Meta Bind 和 Dataview 查询。
- `AI提示词库` 可保留 `类型/提示词`、`提示词库/*`、`提示词分类/*`，但这些标签不作为全库通用标签扩散。
- 状态标签只在需要 Dataview 或任务筛选时使用。
- 不为一次性小概念创建过细标签。
- 能用链接表达关系时，优先用链接，不要堆标签。
- `重要` 用于真正会反复访问或指导行动的笔记。
- 工作流层页面可以使用 `MOC` 或 `工作台`，但正文型知识仍优先使用 `笔记`、`项目`、`资源`。

## 何时建 MOC

满足任一条件再建：

- 一个主题已经有 3 篇以上相关笔记。
- 一个主题跨越多个文件夹。
- 需要为项目、学习或输出建立长期入口。
- 普通索引已经无法解释这个主题的内在关系。

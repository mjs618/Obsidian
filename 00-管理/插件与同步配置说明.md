# 插件与同步配置说明

## 当前插件状态

已安装社区插件：

- Obsidian Git：用于 Git 备份和同步。
- Excalidraw：用于绘图笔记。
- Tasks：用于任务聚合和过滤。
- Calendar：用于日期导航。

当前笔记和模板中还引用了 Dataview 与 Templater 的语法，但这两个插件未出现在社区插件列表中。相关内容可以保留为“未来启用后可用”，但当前不应依赖它们完成日常检索。

## 模板注意事项

- `Templates/Templater` 中的文件使用 `<% ... %>` 语法，需要 Templater 插件。
- `Templates/原生模板` 中的文件更接近 Obsidian 原生模板，可作为不依赖 Templater 的模板来源。
- 当前统一模板入口是 `Templates/00-索引.md`。启用 Templater 前，不应把 `<% ... %>` 文件当作可直接执行的日常模板。

## Dataview 注意事项

部分文档包含 Dataview 查询块，例如标签仪表盘和 DailyNotes 配置说明。未安装 Dataview 时，这些查询不会自动生成结果。

建议后续二选一：

- 安装并启用 Dataview，把仪表盘和索引升级为自动视图。
- 保持无插件方案，把索引改成手动维护列表。

## Excalidraw 路径

当前实际目录是 `90-Excalidraw`，但 Excalidraw 插件配置中仍有旧路径 `Excalidraw` 的痕迹。后续应在 Obsidian 插件设置中检查并改为当前目录，避免新图落到旧目录。

本期只记录问题，不直接修改 Obsidian 插件配置。

## Git 同步边界

当前仓库有 GitHub remote，并且已启用 Obsidian Git 插件。同步前建议遵守：

1. 大规模移动或整理前，先提交当前稳定状态。
2. 只确认变更无误后再 push。
3. 不把无关项目文件、临时缓存、系统文件纳入提交。
4. 自动化任务可以写入 Markdown，但不应自动 `git commit` 或 `git push`，除非之后单独授权。

## 当前优先级

1. 先稳定二期迁移后的新路径，确保索引、自动化和 Git 状态一致。
2. 再清理 `未分类`、空文件、低价值重复入口和缺少标签的正式笔记。
3. 最后再做 Dataview/Templater 自动化增强。

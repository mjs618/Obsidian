## 日常使用

1. 新内容先放到对应分区；无法判断时放入 `未分类`。
2. 正式笔记至少补一个 `领域/*` 和一个 `类型/*` 标签。
3. 重要笔记补一个入口链接，优先链接到分区 `00-索引.md`。
4. 每周检查 `未分类`、`待整理`、空文件和 Git 状态。

## 维护节奏

- 每日：处理新笔记、补标签、记录关键产出。
- 每周：清理 `未分类`，检查 `待整理` 和空日记。
- 每月：复制健康检查模板，做一次库健康审查。
- 每季度：评估标签体系、插件依赖和结构迁移需求。

## 当前边界

本阶段只做稳健治理：新增索引、管理文档、健康检查和同步说明。不移动、不重命名、不删除既有笔记。`AI学习`、`AI日记`、`Templates`、`模版` 的合并留到后续阶段。

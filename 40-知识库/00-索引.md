# 40-知识库索引

## 这个分区负责什么

知识库区保存知识管理方法论、案例、技术方法、实践指南和资源汇总。这里是知识管理主题的主入口。

## 知识库方法地图

```mermaid
flowchart TD
    Concept[基础概念] --> Cases[案例探索]
    Cases --> Methods[技术方法]
    Methods --> Practice[实践指南]
    Practice --> Resources[资源汇总]
    Practice --> Governance[当前库治理]
    Governance --> Tags[标签体系]
    Governance --> Review[健康检查]
    Review --> Improve[结构与内容迭代]
    Improve --> Practice
```

## 整理规则

- 章节内容适合作为长期参考，不建议频繁拆改原文。
- 后续可以从章节中提炼“原则卡片”和“操作清单”，再链接回原章节。
- 新增原则卡片优先汇总到 [[知识库核心知识与构建方法总结]]，避免散落在多个章节里。
- 方法论笔记最终要能服务当前 vault 的使用动作，否则只保留为参考资料。

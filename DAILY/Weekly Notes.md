## 周复盘规则

- 本周推进了哪些项目。
- 哪些阻塞需要下周处理。
- 哪些经验值得沉淀。
- 哪些任务应该关闭、转移或归档。

## 周复盘输出

| 输出 | 去向 |
| --- | --- |
| 下周 1-3 个重点 | [[PARA/Projects]] 或项目页 |
| 项目阻塞 | [[HUB/Tasks]] 或项目下一步 |
| 技术经验 | [[10-技术笔记/00-索引]] |
| 可复用判断 | [[ZETA/Permanent Notes]] |
| 不再推进的项目 | [[PARA/Archive]] |

## 周末检查

- [ ] 收件箱是否还有超过一周的内容？
- [ ] 每个活跃项目是否只有 1-3 个下一步？
- [ ] 本周有没有一条经验值得沉淀？

## 进入 SYSTEM 的条件

- 需要修改模板、标签、属性、Dataview 查询或目录规范。
- 需要调整插件、同步、样式、自动化或后台配置。
- 需要记录一次系统迁移、规则变更或结构性优化。
- 需要检查当前知识库和 Dusk 对标方案的差距。

## 改系统前检查

1. 先确认这是系统问题，不是单篇笔记内容问题。
2. 找到受影响的模板、索引、治理文档和使用说明。
3. 修改后同步更新 [[00-管理/知识库治理规范]] 与 [[00-管理/标签与属性速查]]。
4. 对会影响新建笔记的变更，检查 [[Templates/00-索引]] 和 [[SYSTEM/TEMPLATE/FORMAT]]。

## 不在 SYSTEM 做

- 不写项目正文；项目内容回到 [[PARA/Projects]] 或对应编号目录。
- 不存剪藏原文；资料进入 [[PARA/Resources]] 或 [[80-Clippings/00-索引]]。
- 不堆临时想法；短想法进入 [[STICKY/00-STICKY]] 或 [[HUB/Inbox]]。
- 不把规则讨论无限展开；稳定规则写入治理文档，历史过程归档。

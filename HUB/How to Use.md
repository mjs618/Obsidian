# How to Use

> [!home]+ 最短路径
> 这个库不要从文件夹树开始用。每天打开 [[HUB/Home]]。

> [!info]+ 两层结构
> `HUB / PARA / ZETA / DAILY / STICKY / SYSTEM` 是工作流层，只负责进入和流转；`00-99` 编号目录是内容库层，负责长期保存正文。

> [!capture] 1. 记录
> 不知道放哪里，就放 [[HUB/Inbox]]。

> [!project] 2. 推进
> 工作和项目只看 [[PARA/Projects]]。

> [!task] 3. 整理
> 每周只处理 [[HUB/Tasks]] 里的 1 项。

> [!zeta] 4. 沉淀
> 资料处理后进入 [[ZETA/Permanent Notes]]，不要把原文当知识。

> [!project] 5. 输出
> 能转成文章、方案、SOP 或提示词资产的内容进入 [[HUB/Outputs]]。

> [!daily] 6. 复盘
> 每天只记录一个产出或观察；每周只清理一小批待整理内容。

## 每天打开顺序

1. [[HUB/Home]]：看今天要不要捕获、推进、整理或沉淀。
2. [[HUB/Inbox]]：先放新内容，不急着分类。
3. [[PARA/Projects]]：只推进一个当前最重要的项目。
4. [[HUB/Tasks]]：如果有整理时间，只处理一个页面级任务。
5. [[HUB/Outputs]] 或 [[HUB/Review]]：有余力时，只推进一个输出候选或复习 3 条高价值笔记。
6. [[DAILY/00-DAILY]]：收尾时记录今天最有价值的产出或观察。

## 判断规则

- 有交付物和下一步：看 [[PARA/Projects]]。
- 是长期领域：看 [[PARA/Areas]]。
- 是资料来源：看 [[PARA/Resources]] 或 [[ZETA/Literature Notes]]。
- 是临时想法：看 [[HUB/Inbox]] 或 [[ZETA/Fleeting Notes]]。
- 能形成成果：看 [[HUB/Outputs]]。
- 需要重新带回行动：看 [[HUB/Review]]。
- 已经不活跃但要保留：看 [[PARA/Archive]]。

## 一篇好笔记至少回答

- 它解决什么问题？
- 它来自哪里？
- 它和哪个项目、主题或资料有关？
- 下一次我会在什么场景复用它？

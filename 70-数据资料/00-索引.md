# 70-数据资料索引

## 这个分区负责什么

数据资料区用于保存量表、参考表、原始资料和需要长期引用的数据型内容。

## 核心入口

- [[量表]]

## 重点内容

- [[量表]]

## 整理规则

- 数据资料应记录来源、版本、适用范围和使用方式。
- 如果资料用于工作或研究，应链接到对应项目或主题笔记。
- 大型附件后续可单独放入附件目录，但本期不做迁移。

## 数据资料完成标准

| 字段 | 要求 |
| --- | --- |
| 来源 | 能追溯出处或生成背景 |
| 版本 | 有日期、版本号或适用时段 |
| 适用范围 | 说明用于什么场景，不用于什么场景 |
| 使用方式 | 说明如何读取、计算或引用 |
| 关联 | 链接到项目、主题或资料来源 |

## 不放在这里

- 外部文章和长文剪藏放入 [[80-Clippings/00-索引]]。
- 已经转化成观点的内容放入 [[ZETA/Permanent Notes]]。
- 只服务某个项目的一次性数据，优先放项目页。

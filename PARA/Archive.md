## 归档规则

- 归档前确认文件名、标签、索引或反链能找回。
- 已被新规则替代的历史方案只保留历史参考提示。
- 空文件和本次整理产生的临时文件可以删除；知识正文优先保留。

## 归档判断

| 情况 | 处理 |
| --- | --- |
| 项目完成且暂无复用动作 | 归档，并保留复盘或最终链接 |
| 资料不再处理但仍可能查证 | 归档到来源清楚的位置 |
| 旧规则已被新规则替代 | 归档旧规则，只在当前规则页保留提示 |
| 内容没有来源、上下文和价值 | 删除，不进入归档 |
| 内容仍有下一步或责任人 | 不归档，留在项目或任务入口 |

## 归档后不再做

- 不再把归档内容放入日常任务、项目看板或本周推进清单。
- 不再维护过期方案的细节，只保留历史背景和迁移原因。
- 不把 Archive 当成第二个 Inbox；无法判断的内容先回到 [[HUB/Inbox]] 或 [[未分类/收件箱处理台]]。

## 归档动作

归档时补齐三件事：为什么归档、原来属于哪里、未来如何找回。缺少这三项时，先不要移动文件。

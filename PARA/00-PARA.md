# PARA

> [!home]+ Projects, Areas, Resources, Archive
> PARA 用来按行动状态组织内容。先判断“这件事是否需要推进”，再决定放在哪里。

> [!info]+ 使用边界
> PARA 是行动视角，不是新的正文仓库。项目、领域、资料和归档的正文仍优先留在编号目录中。

> [!project] Projects
> [[PARA/Projects]]
>
> 有结果、有推进、有下一步。

> [!para] Areas
> [[PARA/Areas]]
>
> 长期维护的领域，没有明确截止日期。

> [!zeta] Resources
> [[PARA/Resources]]
>
> 资料、参考、剪藏、模板和工具。

> [!task] Archive
> [[PARA/Archive]]
>
> 不活跃但需要保留。

## 快速判断

| 问题 | 去向 |
| --- | --- |
| 有明确成果和下一步吗 | [[PARA/Projects]] |
| 需要长期维护但没有截止日期吗 | [[PARA/Areas]] |
| 只是资料、来源或参考吗 | [[PARA/Resources]] |
| 不活跃但仍需保留吗 | [[PARA/Archive]] |

## PARA 使用顺序

1. 先问它是否需要推进；有成果、截止、责任或下一步，进入 [[PARA/Projects]]。
2. 再问它是否需要长期维护；没有截止但需要持续关注，进入 [[PARA/Areas]]。
3. 再问它是否只是来源或参考；尚未内化的材料，进入 [[PARA/Resources]]。
4. 最后问它是否已经降频；不再活跃但仍要找回，进入 [[PARA/Archive]]。

## 常见纠偏

| 现象 | 调整 |
| --- | --- |
| 项目页长期没有下一步 | 降到 [[PARA/Areas]]，或归入 [[PARA/Archive]] |
| 领域页开始出现明确交付 | 新建或链接到 [[PARA/Projects]] |
| 资料页已经写出个人判断 | 升级到 [[ZETA/Permanent Notes]] 或主题地图 |
| 归档内容重新变活跃 | 移回对应项目、领域或资源入口 |

## 每周检查

- [[PARA/Projects]] 只保留本周仍可能推进的内容。
- [[PARA/Areas]] 检查是否有失控、缺入口或需要拆成项目的领域。
- [[PARA/Resources]] 清掉只收藏不处理的材料，保留有来源、有用途的资料。
- [[PARA/Archive]] 确认归档内容仍能通过文件名、标签或反链找回。

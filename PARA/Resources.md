## 资料处理规则

- 原文保留在 [[80-Clippings/00-索引]] 或对应资料区。
- 摘要和个人判断进入 [[80-Clippings/剪藏处理台]] 或主题页。
- 能指导行动的内容链接到项目；能长期复用的内容链接到 [[ZETA/Permanent Notes]]。

## 资料完成标准

一条资源不是“收藏了”就完成，至少要满足下面四项中的三项：

- 有来源：保留原文、出处、作者或获取位置。
- 有用途：写明它服务哪个项目、领域、主题或问题。
- 有判断：补一句自己的理解、质疑或可复用结论。
- 有去向：链接到项目、主题地图、Permanent Note 或归档位置。

## 资料升级出口

| 资料价值 | 出口 |
| --- | --- |
| 能直接推动行动 | 链接到 [[PARA/Projects]] 或具体项目页 |
| 能长期复用为观点 | 写入 [[ZETA/Permanent Notes]] |
| 只适合主题跟踪 | 放到对应主题地图或领域索引 |
| 暂时无用途但可能找回 | 保留在 Resources，并补清楚来源 |
| 没有来源、用途和判断 | 删除或移入 [[PARA/Archive]] |

## 处理节奏

- 新资料先少量保留，不急着重写全文。
- 每周只处理最可能复用的资料，低价值收藏直接放弃。
- Resources 里的材料不承担结论功能；结论必须进入 ZETA 或项目上下文。

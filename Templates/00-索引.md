# Templates 索引

## 这个分区负责什么

`Templates` 是人工可读的模板入口，包含原生模板风格文件、Templater 参考文件和标签审查清单。自动化命令实际使用的模板统一放在 `SYSTEM/TEMPLATE/FORMAT`。

## 整理规则

- 自动化入口只引用 `SYSTEM/TEMPLATE/FORMAT`。
- 自动化模板中，`type` 使用中文治理值，`template_type` 保留插件和旧查询需要的精确类型。
- 动态标签脚本必须保留已有 `领域/*`、`类型/*`、`状态/*` 标签，只追加 `project/*`、`area/*`、`contact/*` 等兼容标签。
- `Templates/Templater` 只作为历史参考和模板设计材料。
- 原生模板统一放在 `Templates/原生模板`。
- 新增模板时先判断是“自动化模板”还是“人工参考模板”，不要两边各维护一份。

## 模板完成标准

| 模板类型 | 至少确认 |
| --- | --- |
| 自动化模板 | 调用入口、frontmatter、动态脚本、Dataview 兼容查询 |
| 原生参考模板 | 使用场景、最小字段、不会误导到旧目录 |
| 指南文档 | 和当前 vault 结构一致，不保留旧路径 |

## 不放在这里

- 插件运行配置放在 `.obsidian` 和 [[SYSTEM/必要插件清单]]。
- 当前治理规则放在 [[00-管理/知识库治理规范]]。
- 具体笔记内容不要复制成模板示例长期维护。

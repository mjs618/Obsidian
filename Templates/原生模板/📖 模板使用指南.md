# Obsidian 模板系统使用指南

> [!info]+ 当前规则
> 实际自动化入口统一使用 `SYSTEM/TEMPLATE/FORMAT`；`Templates/原生模板` 只作为人工参考模板和设计材料。维护模板时，优先确认 QuickAdd、Templater、Journals 是否正在调用对应文件。

## 📂 模板列表

本模板系统包含以下模板：

### 📔 日常记录类

1. **📔 日记模板** - 每日反思与记录
   - 包含晨间思考、待办事项、学习输入、工作产出
   - 晚间总结、数据统计、情绪追踪
   - 使用频率：每天

2. **📊 周工作总结模板** - 每周工作复盘
   - 目标回顾、成果展示、数据分析
   - 问题改进、学习计划、下周规划
   - 使用频率：每周五或周日

3. **📅 月度总结模板** - 每月深度复盘
   - 关键成果、数据统计、高光时刻
   - 财务总结、人际关系、下月计划
   - 使用频率：每月末

### 💼 工作学习类

4. **📋 会议记录模板** - 高效会议管理
   - 基本信息、议程记录、行动计划
   - 决策追踪、参考资料
   - 使用频率：每次会议

5. **📚 学习笔记模板** - 知识吸收与整理
   - 核心概念、详细笔记、关键洞察
   - 复习计划、知识关联
   - 使用频率：每次学习

6. **🚀 项目规划模板** - 项目全周期管理
   - 项目概述、时间规划、任务分解
   - 风险管理、进度跟踪
   - 使用频率：每个新项目

7. **📖 读书笔记模板** - 深度阅读记录
   - 书籍信息、章节笔记、精彩摘录
   - 批判性思考、行动计划
   - 使用频率：每本书

### 🎨 创意管理类

8. **💡 灵感卡片模板** - 创意捕获与孵化
   - 核心想法、实现思路、评估等级
   - 使用频率：随时记录

9. **✅ 清单模板** - 任务清单管理
   - 待办事项、进度跟踪
   - 使用频率：按需使用

10. **👥 人脉档案模板** - 人际关系管理
    - 基本信息、互动记录、合作机会
    - 使用频率：认识新人后

## 当前模板分层

| 层级 | 路径 | 用途 |
| --- | --- | --- |
| 自动化模板 | `SYSTEM/TEMPLATE/FORMAT` | QuickAdd、Templater 文件夹模板、Journals 实际调用 |
| 原生参考模板 | `Templates/原生模板` | 手动插入、模板设计参考、非自动化场景 |
| Templater 参考 | `Templates/Templater` | 历史自动标签逻辑和脚本参考 |

## ⚙️ 配置检查

### Templater

- 模板根目录：`SYSTEM/TEMPLATE`
- 文件夹模板主要指向：`SYSTEM/TEMPLATE/FORMAT`
- 新建 `30-工作/项目`、`ZETA/FLEETING`、`DAILY/DAILY` 等目录下文件时，会触发对应自动化模板。

### QuickAdd

- 快速创建 Fleeting、Literature、Permanent、Project、Meeting、Contact 等笔记。
- 捕获日任务时写入 `DAILY/DAILY/{{DATE:YYYY-MM-DD}}` 的 `# New Tasks` 下方。
- QuickAdd 仍依赖自动化模板路径，不依赖原生参考模板。

### Journals

- 日记：`DAILY/DAILY`，模板 `SYSTEM/TEMPLATE/FORMAT/template_daily_note.md`
- 周记：`DAILY/WEEKLY`，模板 `SYSTEM/TEMPLATE/FORMAT/template_weekly_note.md`
- 月记：`DAILY/MONTHLY`，模板 `SYSTEM/TEMPLATE/FORMAT/template_monthly_note.md`

## 🎯 使用方法

### 方法一：使用 QuickAdd

1. 按 `Ctrl/Cmd + P` 打开命令面板
2. 输入 `QuickAdd`
3. 选择 `Multi - Select Note Type`、`Multi - Project`、`Multi - Meeting` 等入口

### 方法二：使用 Journals

使用 Journals 打开或创建日、周、月记录。日记模板中的 `# New Tasks` 不要改名，否则 QuickAdd 的日任务捕获无法定位。

### 方法三：手动插入参考模板

1. 新建笔记
2. 运行 Obsidian 原生模板命令
3. 从 `Templates/原生模板` 选择人工参考模板

## 🏷️ 标签体系建议

正式笔记至少保留一个 `领域/*` 和一个 `类型/*` 标签。常用组合：

| 维度 | 示例 |
| --- | --- |
| 领域 | `领域/技术`、`领域/AI`、`领域/工作`、`领域/知识`、`领域/思维`、`领域/生活`、`领域/阅读`、`领域/数据资料`、`领域/收集箱` |
| 类型 | `类型/笔记`、`类型/项目`、`类型/资源`、`类型/卡片`、`类型/日记`、`类型/会议`、`类型/领域`、`类型/人脉` |
| 状态 | `状态/草稿`、`状态/待整理`、`状态/进行中`、`状态/已完成`、`状态/归档`、`状态/跟踪中` |
| 行动 | `待整理`、`待复习`、`灵感`、`重要`、`问题` |

自动化模板可以额外保留 `project/*`、`area/*`、`contact/*` 等兼容标签，用于 Dataview、Tasks 和 Meta Bind 查询。

## 🔄 模板变量说明

原生参考模板中常见变量：

- `{{date}}` - 当前日期（格式：YYYY-MM-DD）
- `{{time}}` - 当前时间（格式：HH:mm）
- `{{date:YYYY 年 MM 月 DD 日}}` - 自定义日期格式
- `{{title}}` - 笔记标题（需要手动填写）
- `{{project}}` - 项目名称（需要手动填写）

自动化模板中常见 Templater 变量：

- `<% tp.file.title %>` - 当前文件名
- `<% tp.file.creation_date() %>` - 创建时间
- `<%tp.file.cursor()%>` - 插入后光标位置
- `<%* ... -%>` - 执行 JavaScript 脚本，常用于追加动态标签

## ❓ 常见问题

**Q: 模板太多记不住怎么办？**
A: 先从最常用的 3 个开始（日记、学习笔记、会议记录），熟练后再添加。

**Q: 模板字段太多不想填？**
A: 可以删减不需要的字段，保持模板简洁。

**Q: 如何备份模板？**
A: 模板文件在 `E:\Obsidian\SYSTEM\TEMPLATE\FORMAT` 和 `E:\Obsidian\Templates`，已配置 Git 插件会自动备份。

# 📝 Obsidian 模板系统使用指南

## 📂 模板列表

本模板系统包含以下模板：

### 📔 日常记录类

1. **📔 日记模板** - 每日反思与记录
   - 包含晨间思考、待办事项、学习输入、工作产出
   - 晚间总结、数据统计、情绪追踪
   - 使用频率：每天

2. **📊 周工作总结模板** - 每周工作复盘
   - 目标回顾、成果展示、数据分析
   - 问题改进、学习计划、下周规划
   - 使用频率：每周五或周日

3. **📅 月度总结模板** - 每月深度复盘
   - 关键成果、数据统计、高光时刻
   - 财务总结、人际关系、下月计划
   - 使用频率：每月末

### 💼 工作学习类

4. **📋 会议记录模板** - 高效会议管理
   - 基本信息、议程记录、行动计划
   - 决策追踪、参考资料
   - 使用频率：每次会议

5. **📚 学习笔记模板** - 知识吸收与整理
   - 核心概念、详细笔记、关键洞察
   - 复习计划、知识关联
   - 使用频率：每次学习

6. **🚀 项目规划模板** - 项目全周期管理
   - 项目概述、时间规划、任务分解
   - 风险管理、进度跟踪
   - 使用频率：每个新项目

7. **📖 读书笔记模板** - 深度阅读记录
   - 书籍信息、章节笔记、精彩摘录
   - 批判性思考、行动计划
   - 使用频率：每本书

### 🎨 创意管理类

8. **💡 灵感卡片模板** - 创意捕获与孵化
   - 核心想法、实现思路、评估等级
   - 使用频率：随时记录

9. **✅ 清单模板** - 任务清单管理
   - 待办事项、进度跟踪
   - 使用频率：按需使用

10. **👥 人脉档案模板** - 人际关系管理
    - 基本信息、互动记录、合作机会
    - 使用频率：认识新人后

## ⚙️ 配置步骤

### 第一步：移动模板到 Obsidian

1. 将所有模板文件从 `e:\fun\wechat\one\` 复制到你的 Obsidian 笔记库：
   ```
   E:\Obsidian\模版\
   ```

2. 建议删除或重命名现有的 `模版图标.md`

### 第二步：配置 Obsidian 模板插件

1. 打开 Obsidian 设置
2. 进入 **核心插件** → 确保 **模板** 已启用
3. 进入 **选项** → **模板**：
   - **模板文件夹位置**: 选择 `模版`
   - **日期格式**: `YYYY-MM-DD`
   - **时间格式**: `HH:mm`

### 第三步：配置日记插件（可选）

1. 进入 **核心插件** → 确保 **日记** 已启用
2. 进入 **选项** → **日记**：
   - **日记文件夹位置**: `日记` 或 `AI 学习/每日汇总`
   - **模板文件位置**: 选择 `📔 日记模板`
   - **格式**: `YYYY-MM-DD`

### 第四步：创建必要文件夹

建议在 `E:\Obsidian\` 下创建以下文件夹：

```
E:\Obsidian\
├── 00-Inbox/          # 临时收集
├── 01-日记/           # 每日日记
├── 02-项目/           # 项目文档
├── 03-学习/           # 学习笔记
├── 04-工作/           # 工作文档
├── 05-总结/           # 周/月总结
├── 06-人脉/           # 人脉档案
├── 07-创意/           # 灵感卡片
├── 模版/              # 模板文件
└── 99-归档/           # 归档内容
```

## 🎯 使用方法

### 方法一：使用命令面板

1. 按 `Ctrl/Cmd + P` 打开命令面板
2. 输入 `模板：插入模板`
3. 选择需要的模板

### 方法二：使用快捷键

为常用模板设置快捷键：

1. 安装 **QuickAdd** 插件（推荐）
2. 配置模板快捷插入
3. 设置快捷键（如 `Ctrl+Alt+D` 插入日记模板）

### 方法三：手动选择

1. 新建笔记
2. 点击右侧边栏的模板图标
3. 选择模板

## 🔄 模板变量说明

模板中使用了一些动态变量：

- `{{date}}` - 当前日期（格式：YYYY-MM-DD）
- `{{time}}` - 当前时间（格式：HH:mm）
- `{{date:YYYY 年 MM 月 DD 日}}` - 自定义日期格式
- `{{title}}` - 笔记标题（需要手动填写）
- `{{project}}` - 项目名称（需要手动填写）

## ❓ 常见问题

**Q: 模板太多记不住怎么办？**
A: 先从最常用的 3 个开始（日记、学习笔记、会议记录），熟练后再添加。

**Q: 模板字段太多不想填？**
A: 可以删减不需要的字段，保持模板简洁。

**Q: 如何备份模板？**
A: 模板文件在 `E:\Obsidian\模版\`，已配置 Git 插件会自动同步。

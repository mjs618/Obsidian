# 60-思维笔记索引

## 这个分区负责什么

思维笔记区用于保存长期思考、兴趣主题、认知框架和个人方法论。新增内容时，优先写清楚观点、依据、例子和可行动作。

## 整理规则

- 单篇主题较大时，可以拆成“主题索引 + 多篇卡片”。
- 每篇思维笔记至少补一个相关问题或应用场景。
- 与技术、工作或生活相关的思考，应增加跨区链接。

## 思维笔记完成标准

| 阶段 | 至少包含 |
| --- | --- |
| 草稿 | 一个明确问题 |
| 资料型 | 来源、摘录和初步解释 |
| 判断型 | 自己的观点、依据和边界 |
| 可复用型 | 应用场景、相关项目或行动建议 |

## 不放在这里

- 纯外部资料放入 [[80-Clippings/00-索引]] 或 [[ZETA/Literature Notes]]。
- 可执行项目放入 [[30-工作/00-索引]]。
- 日常情绪和生活流水保留在 [[DAILY/00-DAILY]]。
